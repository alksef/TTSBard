# VTube Studio

TTSBard передаёт в VTube Studio состояние набора текста: `1`, пока пользователь печатает, и `0`
после завершения набора. Интеграция работает через локальный VTube Studio Plugin API и не передаёт
текст или звук модели.

## Перед подключением

1. Запустите desktop-версию VTube Studio и загрузите нужную модель.
2. Убедитесь, что Plugin API включён и слушает порт `8001`, либо укажите фактический порт в TTSBard.
3. В TTSBard откройте настройки VTube Studio, сохраните порт и нажмите кнопку подключения.
4. Подтвердите запрос доступа TTSBard в окне VTube Studio. Полученное разрешение можно позднее
   отозвать в настройках Plugin API VTube Studio.

Статус TTSBard должен стать `Connected`. Подключение само по себе не приводит модель в движение:
после него нужно выбрать и настроить одно из действий набора.

## Способы управления моделью

TTSBard поддерживает три способа:

- **Параметр VTS** — TTSBard управляет входным custom-параметром VTube Studio со значениями
  `0..1`;
- **Горячие клавиши** — TTSBard запускает одну VTS Hotkey при начале и другую при окончании набора;
- **Предмет сцены** — выбранный GIF или другой поддерживаемый предмет показывается при наборе и
  скрывается после него.

Этот режим использует не VTS event API, а `ParameterCreationRequest` и
`InjectParameterDataRequest`: TTSBard создаёт и обновляет собственный входной параметр, а
пользователь один раз сопоставляет его с выходным параметром модели в VTS Parameter Setup.

## Настройка параметра VTS

### INPUT и OUTPUT — разные параметры

Не вводите ID Live2D-параметра модели как непосредственную цель отправки. В VTube Studio данные
проходят через два уровня:

```text
TTSBard INPUT TTSBardTyping → Live2D OUTPUT ParamTyping
```

- `TTSBardTyping` — входной custom/tracking parameter VTube Studio. Его создаёт и обновляет плагин
  TTSBard.
- `ParamTyping` — выходной параметр, уже добавленный автором Live2D-модели.

Само наличие `ParamTyping` в Live2D-файле не регистрирует одноимённый INPUT в Plugin API. Поэтому
прямая отправка `ParamTyping` может вернуть тот же error `453`, что и любое другое несуществующее
входное имя.

### Создание INPUT и mapping

1. В TTSBard выберите способ **«Параметр VTS»**.
2. В поле имени оставьте рекомендуемое значение `TTSBardTyping` и сохраните действие.
3. При подключённом VTube Studio запустите тест действия. TTSBard должен создать custom INPUT и
   отправить тестовый импульс.
4. В VTube Studio откройте настройки загруженной модели и раздел **VTS Parameter Setup**.
5. Добавьте mapping или откройте строку для `ParamTyping`.
6. Выберите в поле INPUT custom-параметр `TTSBardTyping`; VTube Studio должен показывать, что он
   добавлен плагином TTSBard.
7. Выберите в поле OUTPUT Live2D-параметр `ParamTyping`.
8. Для дискретного индикатора задайте диапазоны INPUT `0..1` и OUTPUT `0..1`. Если модель использует
   другой диапазон, измените только OUTPUT в соответствии с ригом.
9. Установите smoothing в `0` или минимальное подходящее значение и сохраните настройки модели.
10. Повторите тест: `ParamTyping` должен перейти `0 → 1 → 0`.

Один Live2D OUTPUT можно выбрать только в одном обычном input mapping. Если `ParamTyping` уже
управляется другой строкой, сначала определите, какой источник должен владеть им.

## Настройка Hotkeys

1. В настройках загруженной модели VTube Studio создайте две Hotkey: для начала и окончания набора.
2. Назначьте им нужные выражения, анимации или другие действия модели.
3. Подключите TTSBard и выберите способ **«Горячие клавиши»**.
4. Нажмите **«Загрузить Hotkey»**, выберите отдельные действия для начала и окончания набора и
   сохраните действие.
5. Запустите тест и проверьте оба перехода. Учитывайте cooldown конкретных Hotkey и toggle-семантику
   выражений VTube Studio.

## Настройка предмета сцены

1. Загрузите предмет в текущую сцену VTube Studio и настройте его положение, размер и слой.
2. Подключите TTSBard и выберите **«Предмет сцены»**.
3. Нажмите **«Обновить предметы»**, выберите файл и сохраните действие.
4. Если в сцене несколько экземпляров одного файла, оставьте один: TTSBard не выбирает экземпляр
   произвольно.
5. Запустите тест. Предмет должен показаться на время заданного таймаута и затем скрыться.

## Диагностика

### Error 453

VTube Studio не нашёл указанное имя среди default/custom INPUT-параметров. Перед первым тестом
TTSBard создаёт custom INPUT сам; если 453 всё же возникает, проверьте, что:

- в поле TTSBard указано имя INPUT, а не Live2D OUTPUT `ParamTyping`;
- доступ плагина не был отозван: при отзыве VTube Studio удаляет custom parameters этого plugin
  identity, и INPUT нужно создать заново (тест после повторного подключения сделает это);
- используется актуальная версия TTSBard.

### INPUT изменяется, но модель не реагирует

Проверьте mapping `TTSBardTyping → ParamTyping`, диапазон OUTPUT и smoothing. Выражение, анимация или
physics могут перезаписывать значение того же Live2D-параметра даже при работающем INPUT.

### Error 454

Параметр уже контролируется другим плагином в режиме `set`. Остановите конфликтующий источник либо
выберите отдельный custom INPUT и настройте для него mapping.

# Интеграции

Выберите сценарий подключения. Пользовательские настройки внешней программы
и TTSBard описаны вместе; HTTP/SSE-контракты предназначены для авторов клиентов.

## Подключить внешнюю программу

| Задача | Инструкция |
|---|---|
| Показать реплики в OBS | [WebView: оверлей для OBS](./webview.md) — запуск, адреса, шаблоны, внешний доступ и диагностика. |
| Получать текст и состояние набора своим клиентом | [SSE: контракт для клиентов](./sse.md) — endpoints, события, авторизация, примеры и ограничения доставки. |
| Передавать игровой текст из LunaTranslator | [LunaTranslator → TTSBard](./lunatranslator/README.md) — установка selfbuild-скрипта и настройка отправки. |
| Отправлять текст из другой программы | [Входящий сервер](../user/input-server.md) — HTTP API, очередь и ручной разбор реплик. |
| Показывать набор текста на модели VTube Studio | [VTube Studio](./vtube-studio.md) — Plugin API, INPUT/OUTPUT, Hotkeys и предмет сцены. |
| Дублировать реплики в Twitch Chat | [Настройка Twitch](./twitch.md) — подключение и восстановление соединения. |
| Отправлять реплики и индикатор набора в VRChat | [VRChat: вывод в Chatbox](./vrchat.md) — включение OSC, параметры UDP, маршруты и форматирование. |

WebView/SSE — исходящий текстовый поток. Входящий HTTP-сервер принимает реплики
для озвучивания. Это разные серверы: по умолчанию порты `10100` и `10101`
соответственно. Входящий сервер принимает текст на этом компьютере и из локальной сети;
доступ можно защитить токеном.

## Распознавание экрана и модели

Встроенный OCR находится в панели «Интеграция» приложения, но работает без
внешнего клиента. [Руководство по OCR](../user/ocr.md) содержит ссылки на файлы
модели eSlav PP-OCRv5 Mobile, манифест, структуру папок и проверку распознавания.

Если захват и перевод уже выполняет LunaTranslator, используйте его скрипт;
отдельно включать встроенный OCR TTSBard для этого не требуется.

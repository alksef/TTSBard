# Интеграции

Поддерживаемые контракты и инструкции для внешних систем: OBS/WebView, Twitch,
Telegram, VTube Studio и других интеграций TTSBard.

## Документы

- [VTube Studio](./vtube-studio.md) — подключение Plugin API, настройка параметра, Hotkeys и предмета сцены.
- [WebView Server](./webview.md) — настройка HTTP-сервера, API и модель
  безопасности.
- [SSE Integration](./sse.md) — события, endpoint и подключение клиентов.

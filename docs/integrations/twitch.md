# Twitch Chat

Отправка TTS сообщений в Twitch чат для дублирования.

**Настройка:**
1. Создайте Twitch бота на [twitchtokengenerator.com](https://twitchtokengenerator.com)
2. Скопируйте OAuth токен со страницы (только сам токен, без префикса)
3. Введите данные в настройках Twitch Chat
4. Нажмите Start для подключения к чату

**Поля настроек:**
- **Username / Логин** — логин аккаунта OAuth-токена, 1–25 латинских букв,
  цифр или `_` (без `@` и пробелов)
- **Token** — только токен (без `oauth:`)
- **Channel / Канал** — имя канала без URL и `#`, например `twitchdev`;
  1–25 латинских букв, цифр или `_`

Если первое подключение не подтверждено за 30 секунд, попытка останавливается
со статусом ошибки. Проверьте имя канала и соединение, затем повторите
подключение вручную.

После временного обрыва сети или команды Twitch `RECONNECT` приложение само
переподключается. В заголовке на это время отображается состояние подключения;
ручное «Отключиться» останавливает фоновые попытки. Реплика, при отправке
которой оборвалось соединение, не посылается повторно автоматически: её стоит
отправить снова только если это уместно.

Перед отправкой выберите [маршрут редактора](../user/editor.md#маршрут-фразы), включающий Twitch. Входящие HTTP/OCR автоматически в чат не отправляются.

Ошибки формата показываются рядом с полем до исправления. Если логин не
соответствует аккаунту OAuth-токена, подключение прекращается сразу с отдельным
сообщением. Причина ошибки подключения остаётся в панели до новой попытки либо
отключения; уведомление об успешном сохранении её не скрывает.

Лог приложения содержит коды причин отказа и сведения о повторной попытке.
Сырой IRC-трафик сторонней библиотеки не выводится даже при TRACE, поскольку
команды PASS и PRIVMSG содержат токен и пользовательский текст.

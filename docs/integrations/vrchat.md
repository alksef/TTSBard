# VRChat: вывод в Chatbox

Интеграция с VRChat передаёт готовую реплику в чатбокс над головой аватара
через OSC (Open Sound Control) по UDP. Во время набора текста в редакторе она
также показывает индикатор набора. Черновик реплики в VRChat не передаётся.

## Включение OSC в VRChat

Для приёма сообщений чатбокса в клиенте VRChat должен быть включён приём OSC:

1. Откройте круговое Action Menu (клавиша `R` на клавиатуре или зажатие кнопки меню на контроллере шлема).
2. Перейдите в раздел: `Expressions` → `Options` → `OSC`.
3. Установите переключатель `OSC` в положение `Enabled`.

## Параметры подключения

- **Хост** — по умолчанию `127.0.0.1` (если TTSBard и VRChat запущены на одном компьютере).
- **Порт** — по умолчанию `9000` (стандартный входящий UDP-порт VRChat для OSC).
- **Запускать при старте приложения** — включает вывод автоматически при запуске TTSBard.
  Без этой галки вывод после запуска выключен, даже если в прошлой сессии его запускали кнопкой.
- **Исходящая передача (Send-only)** — доставка пакетов выполняется в один конец по UDP.
  TTSBard не открывает локальный слушающий сокет и не ожидает подтверждений от клиента.
  По этой причине состояние в интерфейсе отображается как «Вывод включён» или
  «Вывод выключен»; оно не подтверждает приём пакетов клиентом VRChat.
  Когда вывод включён, в заголовке окна появляется значок сообщения с подсказкой
  об исходящей отправке. Значок исчезает при остановке вывода.

В блоке «Тестовое сообщение» можно отправить текст вручную после включения
вывода. Уведомление «OSC-сообщение отправлено по UDP» означает успешную отправку
пакета, а не подтверждение показа текста в VRChat. Ошибка выводится там же во
всплывающем уведомлении панели.

## Ограничения и форматирование Chatbox

- **Лимит 144 символа** — VRChat указывает максимум 144 символа для Chatbox.
  TTSBard консервативно считает скалярные значения Unicode; если реплика длиннее 144,
  копия для VRChat усекается с добавлением многоточия (`…`) без разрыва
  графемного кластера. Озвучка и исходный текст остаются без изменений.
- **Отображение строк** — Chatbox VRChat отображает до 9 строк текста одновременно.
- **Формат пакета** — текст передаётся по OSC-адресу `/chatbox/input` с аргументами:
  `[строка, direct=true, notification=true]` (сообщение отображается сразу без открытия клавиатуры).

## Индикатор набора (Typing indicator)

- При наборе текста в редакторе TTSBard отправляется OSC-сообщение `/chatbox/typing [true]`,
  вызывающее анимацию трёх точек над аватаром в игре.
- По истечении таймаута бездействия клавиатуры (настраивается в параметрах редактора)
  или при отправке реплики отправляется `/chatbox/typing [false]`.
- Передачу индикатора набора можно отключить кнопкой на панели редактора вместе с другими интеграциями.

## Маршрутизация

Доставка в VRChat согласуется с выбранным [маршрутом фразы](../user/editor.md#маршрут-фразы):

- **«Везде» (`everywhere`)** — текст озвучивается и отправляется во все активные каналы, включая VRChat.
- **«Без Twitch» (`no_twitch`)** — текст озвучивается, выводится в WebView и VRChat, но не отправляется в чат Twitch.
- **«Только голос» (`voice_only`)** — текст озвучивается голосом, отправка в VRChat пропускается.
- **«Только Twitch» (`twitch_only`)** — текст отправляется в Twitch, отправка в VRChat пропускается.

Для [входящих реплик](../user/incoming.md#автоматическая-озвучка) VRChat входит
в маршруты «Без Twitch» и «Везде». Маршруты «Голос» и «Голос + Twitch»
его исключают.

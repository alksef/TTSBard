# ROADMAP-093 — Шрифт и размер текста редактора

## Outcome

В «Настройки → Редактор» первой карточкой добавлена компактная строка
«Шрифт [селектор] Размер [число] px» с коротким предпросмотром.
На узкой ширине поля переносятся на следующую строку.

- Шрифты: по умолчанию (существующая цепочка JetBrains Mono / Cascadia Code /
  monospace), системный (Segoe UI), Arial, Georgia, Consolas; у каждого есть fallback.
- Размер: 12–32 px, целые значения, исходный размер 16 px.
- Настройки сохраняются между запусками и применяются к рабочим вкладкам
  обычного и компактного редактора без пересоздания документа.
- Placeholder использует выбранную типографику; межстрочный интервал — 1.6.
- Шрифт остальных элементов интерфейса, истории, входящих и внешнего WebView
  не меняется.
- При записи поля временно недоступны. Невалидный ввод не сохраняется;
  ошибка записи показывается рядом с полями, возвращается подтверждённое значение.
- Старые настройки получают defaults; повреждённое значение нового поля
  восстанавливается отдельно, сохраняя остальные настройки.

## Проверка

Пройдены целевые Rust-тесты сохранения/валидации, `cargo check` через
`scripts/cargo.ps1`, frontend-тесты, production frontend build и сверки IPC/DTO.
В браузерном стенде с реальными Vue/CodeMirror-компонентами и тестовым IPC
проверены обе темы, ширины 380/1000 px, крайние размеры, placeholder,
сохранность текста/выделения/undo, ошибка записи и повторная попытка.
Запущенный пользовательский native-процесс не заменялся; полный native smoke
с обновлённым исполняемым файлом в этой сессии не выполнялся.

## Отложенный scope

Полный список установленных шрифтов, установка новых шрифтов, отдельные
настройки на вкладку, масштабирование горячими клавишами и оформление
автодополнения не входят в первую версию.

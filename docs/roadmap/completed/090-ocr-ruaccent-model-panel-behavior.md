# ROADMAP-090 — Единое поведение моделей OCR и RUAccent

## Цель

Сделать выбор и обновление локальных моделей предсказуемыми: панель сохраняет
структуру без моделей, удаление выбранной модели отключает функцию, а появление
файлов само по себе её не включает.

## Исходная проблема

- OCR сохранял включённую галку после удаления модели; ошибка запуска скрывалась
  пустым состоянием, хотя сохранённое включение оставалось.
- Кнопка обновления OCR перемещалась от селектора к галке, когда моделей не было.
- RUAccent скрывал селектор и показывал снятую галку без изменения сохранённой
  настройки. Кнопки обновления не было; список брался из discovery при запуске.

## Текущее состояние

Backend и frontend реализованы; итоговая проверка завершена:

- добавлены настоящее повторное сканирование OCR/RUAccent, согласование выбора
  с найденными моделями и сохранение отключения после неудачного запуска;
- панели сохраняют селектор и обновление списка в пустом состоянии, показывают
  модель «(в памяти)» и доступные для неё элементы управления;
- RUAccent ожидает готовность backend discovery перед стартовой загрузкой;
  добавлен повтор пустого стартового сканирования;
- ошибки запуска OCR видны глобальным уведомлением независимо от открытия
  панели OCR.

Независимое полное ревью консолидированного дерева выполнено. По его результатам
исправлены сохранение ID при пустом сканировании, приоритет живого runtime
RUAccent при обновлении, полная выгрузка RUAccent при отключении и гонка
отключения OCR через обновление списка с параллельным запуском. Повторные
автоматические тесты и строгий Clippy проходят.

2026-09-04 пользователь подтвердил работоспособность перечисленных lifecycle-сценариев
с реальными локальными моделями; направление завершено.

## Согласованное поведение

| Состояние | Поведение обеих панелей |
|---|---|
| Нет моделей | Селектор виден и заблокирован; «Модели не найдены» — недоступная подсказка, а не выбираемый пункт. Галка включения снята и недоступна. Под селектором сноска с путём к каталогу моделей. |
| Одна модель | Единственная модель выбирается автоматически, выбор сохраняется; включение остаётся действием пользователя. |
| Несколько моделей | Сохраняется доступный прежний выбор; без него показана недоступная подсказка «Выберите модель». |
| Выбранная удалена, но runtime держит её в памяти | Обновление ничего не выгружает и не меняет галки; в селекторе модель остаётся выбранной с пометкой «(в памяти)». Выгрузка — переключением на другую модель или снятием галки. |
| Выбранная удалена и в памяти её нет | Функция отключается с сохранением настройки: галки снимаются, у RUAccent также `load_on_start`. Единственная оставшаяся модель выбирается автоматически; при нескольких требуется выбор пользователя. |
| Модели добавлены | Обновление делает селектор доступным и применяет правила выбора выше; само обновление не включает функцию и не загружает модель. |
| Выбранная остаётся доступной | Обновление сохраняет выбор и включение, не перезапускает исправный runtime. |

Единое правило галки: она включена, только пока функция реально работает. Любая
неудачная попытка загрузки или старта — при запуске приложения, ручном включении,
смене модели или обновлении списка — снимает галку с сохранением настройки; ошибка
остаётся видимой на панели. Повтор — снова поставить галку; у RUAccent кнопка
«Загрузить» остаётся отдельным retry.

- Обновление списка выполняется только кнопкой рядом с селектором, включая пустое
  состояние; `title` и `aria-label` «Обновить список моделей». RUAccent получает
  настоящее повторное сканирование каталогов; обновление не загружает и не
  включает ничего.
- Ошибка запуска не прячется пустым состоянием: статус-ошибка видна на панели.
- При пустом списке идентификатор удалённой выбранной модели сохраняется: возврат
  файлов и повторное включение восстанавливают работу, включение автоматически
  не возвращается. При наличии других моделей действуют правила выбора из
  таблицы выше.
- RUAccent с `load_on_start=false` при старте ничего не грузит и настройки не меняет.
- Применять ударения можно только после успешной загрузки; загрузка, автозагрузка и
  применение ударений сохраняют своё назначение.
- Ошибка чтения каталога намеренно не отличается от отсутствия моделей: любая
  неудача загрузки снимает галку, сбой виден на панели. Различение причин — вне
  этого item.

## Этапы

1. Backend: единое правило снятия галки при неудачной загрузке (запуск приложения,
   ручное включение, смена модели, обновление списка); команда настоящего ре-скана
   RUAccent; reconcile обновления — снятие при отсутствии модели нигде, авто-выбор
   единственной, сохранение работающего runtime «в памяти»; живые слоты пропавших
   паков RUAccent не дропаются.
2. Frontend: постоянная строка селектора и кнопки обновления обеих панелей, пометка
   «(в памяти)», видимые ошибки запуска, пустые состояния и сноски, обе темы.
3. Проверить сценарии ниже и записать результат независимого ревью. Конкретные
   implementation tasks и логи вести в `.work/ai/` по AI-assisted workflow.

## Критерии готовности

- Включить функцию, закрыть приложение, удалить модель, запустить: галка снята,
  отключение сохранено и не отменяется следующим запуском или возвратом файлов;
  ошибка видна на панели.
- Вручную включить функцию при битой или отсутствующей модели: галка снимается
  автоматически с сохранением, ошибка видна; повторное включение после починки
  работает.
- Удалить выбранную модель при работающем runtime и нажать обновление: работа не
  прерывается, селектор показывает «(в памяти)»; переключение на другую модель
  выгружает старую.
- Обновление при удалённой и не загруженной модели: галки сняты и сохранены;
  единственная оставшаяся выбрана автоматически, при нескольких — «Выберите модель».
- Добавить файлы и нажать обновление без перезапуска: обе панели видят новый
  список, RUAccent действительно ре-сканирует каталоги; ничего не грузится и не
  включается.
- При обновлении с доступной выбранной моделью её работа не прерывается.
- RUAccent: `load_on_start=false` при старте ничего не меняет; кнопка «Загрузить» —
  единственный retry загрузки, отделена от обновления списка.
- Проверены 0, 1 и несколько моделей; селектор и обновление сохраняют место в
  пустом состоянии; обе темы и узкая панель читаемы, горизонтального переполнения
  нет.

## Outcome

OCR и RUAccent получили согласованные выбор и повторное сканирование моделей,
постоянные элементы управления в пустом состоянии и видимые ошибки запуска.
Обновление сохраняет работающую модель «в памяти», а отсутствие пригодного
runtime или неудачный запуск отключает функцию с сохранением настройки.

OCR со стартом и неполная выгрузка отключённого RUAccent.

# ROADMAP-064 — Интерактивная закреплённая SoundPanel

## Outcome

Плавающая SoundPanel вызывается глобальной горячей клавишей, получает фокус и
позволяет запускать привязанные звуки клавишами A–Z или кликом по карточке.
Перед показом запоминается внешнее foreground-окно, обычно игра. При повторном
вызове уже видимой, но неактивной панели текущее внешнее окно запоминается
заново; вызов уже сфокусированной панели не перезаписывает сохранённый HWND.

В разделе «Звуковая панель» главного окна находится persisted-флаг
«Оставлять панель открытой». Он задаёт единую политику для выбора звука и Esc:

- флаг выключен: панель скрывается, затем фокус явно возвращается предыдущему
  внешнему окну;
- флаг включён: панель остаётся видимой, но фокус всё равно явно возвращается
  предыдущему внешнему окну.

При выборе звука оконная операция и возврат фокуса полностью выполняются до
вызова воспроизведения. Esc выполняет ту же оконную последовательность без
запуска звука. Кнопка закрытия `×` остаётся явным закрытием и всегда скрывает
панель.

Закреплённая панель игнорирует автоматическое скрытие при потере фокуса,
остаётся поверх игры и может быть перемещена за заголовок. В заголовке
показывается индикатор «панель закреплена». Click-through по-прежнему отключает
взаимодействие мышью.

Ручной сценарий с реальной игрой подтверждён пользователем 2026-08-03: вызов
горячей клавишей, оба режима checkbox, возврат фокуса до воспроизведения, Esc,
клики по звукам и перетаскивание панели работают по контракту.

## Продуктовый контракт

1. Глобальная горячая клавиша всегда показывает и фокусирует SoundPanel.
2. Скрытая панель запоминает активное внешнее окно перед показом.
3. Видимая, но неактивная панель при повторном хоткее заново запоминает текущее
   внешнее окно и получает фокус.
4. Видимая и уже активная панель не заменяет сохранённое внешнее окно своим
   HWND.
5. Без `stay_visible` выбор звука выполняет строго
   `hide → restore focus → play`.
6. С `stay_visible` выбор звука выполняет строго
   `leave visible → restore focus → play`.
7. Esc без `stay_visible` выполняет `hide → restore focus`, а с ним —
   `leave visible → restore focus`.
8. `hide_on_blur` скрывает панель только при
   `hide_on_blur && !stay_visible`.
9. Backend runtime-состояние является источником значения `stay_visible` для
   воспроизведения, Esc и обработки потери фокуса.
10. В закреплённом режиме успешно восстановленный HWND сохраняется для
    следующих кликов по видимой панели; повторный хоткей может заменить его
    текущим внешним окном.
11. Карточки звуков и клавиши A–Z используют один backend pipeline
    `sp_play_binding`.

## Интерфейс

- checkbox расположен на основной вкладке «Звуковая панель» и называется
  «Оставлять панель открытой»;
- заметка рядом объясняет возврат фокуса до воспроизведения, поведение Esc и
  перетаскивание панели за заголовок;
- открытая панель немедленно получает обновление настройки и показывает
  индикатор «панель закреплена»;
- кнопка `×` не зависит от checkbox и всегда закрывает панель.

## Проверки

- порядок операций для выбора звука в обоих режимах;
- продолжение воспроизведения после ошибки возврата фокуса;
- порядок операций Esc в обоих режимах;
- политика `hide_on_blur` для обычной и закреплённой панели;
- сохранение HWND для скрытой, видимой неактивной и видимой активной панели;
- повторные клики по оставшейся видимой панели возвращают фокус той же игре;
- frontend tests, production build и проверка IPC-контрактов;
- проверка документации и `git diff --check`.

## Не входит

- изменение глобальной горячей клавиши;
- новый механизм сохранения геометрии окна;
- изменение политики одновременного воспроизведения звуков;
- отдельный пользовательский флаг always-on-top: окно использует существующую
  конфигурацию Tauri, а `stay_visible` управляет его скрытием и возвратом фокуса.

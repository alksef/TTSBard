# ROADMAP-094 — Полный системный каталог шрифтов редактора

## Цель

В первом открытии «Настройки → Редактор» доступен полный список установленных
в Windows семейств шрифтов, как в Luna. Никакой отдельной кнопки загрузки и
задержки до первого списка нет.

## Решение

Rust перечисляет семейства через DirectWrite во время инициализации до
`backend-ready`, нормализует и держит их в памяти. Vue получает готовый каталог
по IPC, показывает быстрые fallback-варианты и поиск по всем семействам.
Выбранное имя хранится как строка; удалённый впоследствии шрифт безопасно
переходит на fallback редактора.

## Границы

В работу не входят установка шрифтов, выбор конкретного начертания, загрузка
шрифта из файла или доступ к шрифтам через WebView API.

## Outcome

- Rust один раз перечисляет системную коллекцию DirectWrite до готовности
  backend и держит каталог в состоянии Tauri; команда
  `get_system_font_families` отдаёт готовый список без повторного сканирования.
  При сбое DirectWrite каталог деградирует до встроенных пунктов с warn в лог.
- Каталог всегда содержит быстрые пункты «По умолчанию» и «Системный», имена
  очищаются, сортируются и дедуплицируются; отображаемое имя выбирается по
  локали `ru-RU`, при отсутствии — первое доступное.
- `EditorSettings.font_family` — строка: старые id `default`, `system`,
  `arial`, `georgia`, `consolas` сохраняют прежнее CSS-поведение; любое
  непустое имя валидно и сохраняется. Пустое значение отвергается без записи;
  повреждённое значение на диске возвращается к `default`, не затрагивая
  остальные настройки. Удалённый из Windows шрифт не стирает настройку.
- Пикер настроек: поиск по имени, сообщение о пустом результате, выбранное
  имя отображается даже при его отсутствии в каталоге.
- CSS для произвольного имени экранирует кавычки и backslash и использует
  текущий шрифт редактора (`var(--font-mono)`) как fallback.

## Проверка

Пройдены целевые Rust-тесты `editor_font`/`system_fonts` (12/12), clippy через
`scripts/cargo.ps1` (единственный warning предсуществующий, в symphonia),
rustfmt по затронутым файлам, `check:settings`, `check:ipc`, vitest (890/890,
включая обновлённые контракты каталога и произвольных имён) и production
frontend build. Пользователь вручную проверил обе темы: открытие пикера,
поиск и прокрутку полного списка, выбор с перезапуском приложения и сценарий
удалённого ранее шрифта (fallback редактора и смена выбора).

Известный остаток вне рамок задачи: fmt-drift репозитория относительно
rustfmt 1.9.0 (`single_instance.rs`, `tts/silero.rs`) — закрывается отдельным
housekeeping-коммитом.

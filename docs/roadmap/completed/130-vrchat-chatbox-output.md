# ROADMAP-130 — Вывод текста и индикатора набора в VRChat

## Цель

Добавить необязательный исходящий канал VRChat Chatbox: пока пользователь
набирает текст в редакторе TTSBard, VRChat показывает индикатор набора; после
отправки фразы общий пайплайн доставляет в chatbox итоговый текст. Интеграция
выключена по умолчанию и не влияет на озвучку или другие каналы.

## Контекст и принятые границы

- VRChat принимает OSC-сообщения `/chatbox/typing` и `/chatbox/input` по UDP;
  стандартная локальная цель — `127.0.0.1:9000`. Отдельный сервер TTSBard и
  чтение сообщений VRChat не нужны. [OSC Overview](https://docs.vrchat.com/docs/osc-overview),
  [OSC as Input Controller](https://docs.vrchat.com/docs/osc-as-input-controller).
- Показывать набираемый черновик не требуется. Несколько вкладок редактора не
  должны становиться источниками периодически публикуемого текста.
- Для индикатора использовать существующий `useTypingBurst` вместе с VTube
  Studio и WebView, без новой машины состояний и специальных правил смены
  вкладки в этом этапе.
- Для итоговой фразы использовать существующие точки внешней доставки текста,
  включая отправку из редактора и прочие входы общего speech pipeline. Не
  отправлять непосредственно из кнопки редактора, чтобы не потерять маршруты,
  текст после обработки и другие источники.
- В редакторе маршрут «Везде» включает VRChat; «Без Twitch» также включает
  VRChat; «Только голос» и «Только Twitch» исключают его. Существующее
  поведение WebView/Twitch и озвучки не меняется.
- Один speech job создаёт не более одного сообщения VRChat. Копия текста для
  VRChat при превышении 144 символов обрезается с конечным `…` на целой
  Unicode-границе; исходный текст, история и озвучка не изменяются. Не
  разбивать фразу на серию сообщений. VRChat показывает максимум 9 строк,
  включая автоматический перенос: точный вид зависит от клиента и требует
  ручной проверки, а не предположения о фиксированной ширине строки.

## Направление реализации

1. Добавить настройку исходящей интеграции с безопасными значениями по
   умолчанию: выключено, адрес `127.0.0.1`, порт `9000`. Панель интеграции
   оформлять по действующим UI-ориентирам и обновить карту UI.
2. Для кодирования OSC рассмотреть `rosc` с уже используемым
   `tokio::net::UdpSocket`. `rosc` предоставляет типизированные сообщения и
   `encoder::encode`; `nannou_osc` добавляет оболочку отправителя поверх
   `rosc`, а ручное кодирование усложняет поддержку формата. Перед внедрением
   проверить совместимость зависимости и lockfile.
3. Подключить VRChat как потребителя переходов набора в `useTypingBurst`:
   `/chatbox/typing true` при начале и `false` при штатной остановке.
4. Подключить `/chatbox/input` к общей доставке готового текста. Проверить оба
   существующих backend-пути WebView/Twitch, маршрут и выбор очищенного текста
   без служебного префикса или разметки TTS-провайдера.
5. Ошибка отправки UDP не должна прерывать речь или другие каналы. Успешная
   запись датаграммы не подтверждает, что VRChat показал сообщение.

## Проверка готовности

- При выключенной интеграции OSC-пакеты не отправляются; существующие каналы
  сохраняют прежнее поведение.
- Локальный UDP-приёмник подтверждает адреса OSC, типы и порядок аргументов,
  переключение индикатора, одно итоговое сообщение и маршруты.
- Проверены пустой текст, кириллица и составные Unicode-символы, граница
  144 символов и обрезка с `…` только копии для VRChat.
- `npm test`, `npm run build`, релевантные Rust-тесты и check через
  `scripts/cargo.ps1`, а также `scripts/check-docs.ps1` проходят.
- Ручная проверка в VRChat подтверждает индикатор, итоговый текст, предел
  отображаемых строк и поведение при выключенном OSC. Применимые состояния UI
  проверены в обеих темах и при узкой ширине.

## Вне scope первого этапа

Публикация черновика, чтение чата VRChat, OSCQuery, синхронизация текста с
проигрыванием звука и разбиение длинных фраз на несколько chatbox-сообщений.

## Outcome

Исходящая интеграция VRChat OSC подключена к общему пайплайну готового текста
и существующему индикатору набора. Добавлены настройки, тестовая отправка и
панель в общем стиле интеграций. Автоматические проверки пройдены; пользователь
подтвердил проведение ручных проверок в VRChat и закрыл направление 2026-10-08.
Подробный протокол проверенных сочетаний тем, размеров окна и состояния OSC не
фиксировался.

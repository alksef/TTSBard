# ROADMAP-081 — Запуск сразу в компактном режиме

Статус: in progress
Дата: 2026-08-20
Приоритет: P2

## Контекст

Компактный режим (уменьшенное окно только с редактором) включается вручную
кнопкой в углу или локальной клавишей `Ctrl+M`. Пользователь, который почти
всегда работает в компактном режиме, вынужден после каждого старта приложения
сворачивать окно вручную.

Дополнительно: режим исторически назывался «минимальный режим», что путается со
«свернуть окно / трей» и расходится с внутренним именованием (`compact_*`).
Решено переименовать пользовательское название в «компактный режим».

## Задачи

1. **Настройка запуска в компактном режиме**
   - Новое поле `start_compact: bool` (serde default `false`) в `GeneralSettings`.
   - DTO: `GeneralSettingsDto.start_compact` + команда `set_start_compact`
     по образцу `set_show_playback_on_start`.
   - Галка первым блоком в `SettingsGeneral.vue`: «Запускать в компактном
     режиме», hint — при старте окно открывается уменьшенным (только редактор).
   - Бэкенд `setup.rs`: перед `main_window.show()` при включённой настройке
     применить компактивные границы (`set_main_bounds`-логика) и resize к
     сохранённым `compact_width/height` (окно ещё невидимо).
   - Фронтенд на старте: если настройка включена, выставить `isMinimalMode =
     true` (App.vue / MinimalModeButton), чтобы UI-состояние совпадало с
     реальным размером окна. Выход — штатная кнопка / `Ctrl+M`.
2. **Переименование «минимальный режим» → «компактный режим»** (только
   пользовательские строки, без переименования кодовых идентификаторов
   `minimal_mode` / `toggle_minimal_mode` — они остаются как есть):
   - MinimalModeButton: title кнопки «Компактный режим».
   - HotkeysPanel: подпись строки хоткея.
   - `commands/hotkeys.rs`: тексты конфликтов («переключения компактного
     режима»).
   - CHANGELOG 0.22.0 (не выпущена) и docs/user/guide.md.
3. Тесты: Rust на новое поле/команду, обновить settings fixtures, фронтенд-тесты
   при необходимости.

# ROADMAP-075 — Полировка action bar редактора и titlebar-статусов

## Контекст

После ROADMAP-073 (route selector, typing toggle, звёздочка дефолта) и
ROADMAP-074 (integration status cluster в titlebar) накопились замечания
пользователя к читаемости, консистентности иконок и визуальному шуму. Каждый
пункт небольшой, но все они касаются одной зоны — editor action bar и правой
части titlebar — и должны решаться вместе, чтобы не гонять UI-правки по
одному.

## Пункты

### 1. Иконка «Передавать набор»

Сейчас в full mode — текстовый label «Передавать набор» с чекбоксом, в compact
— иконка `Keyboard`. Заменить на одну иконку `Keyboard` в обоих режимах с
двумя визуальными состояниями:

- включено — обычный цвет иконки, `aria-pressed="true"`;
- выключено — приглушённая иконка (dim/opacity, допустим диагональный slash
  поверх);

tooltip/aria-label сохраняет полную формулировку «Передавать набор текста
(WebView, VTube Studio) — включено/выключено». Цвет не единственный носитель
смысла.

### 2. Звёздочка дефолта — внутрь списка маршрутов

Убрать отдельную кнопку-звёздочку рядом с RouteSelector (InputPanel.vue).
В дропдауне RouteSelector слева у каждой строки появляется иконка звезды:

- залитая звезда = маршрут по умолчанию, контурная = нет;
- клик по звезде делает маршрут дефолтом (`set_editor_default_route`) и
  `stopPropagation` — не выбирает маршрут текущей фразы;
- клик по остальной строке — выбор маршрута, как сейчас;
- keyboard-навигация: отдельная клавиша (например `Ctrl+Enter` или `D`) на
  активной строке ставит дефолт; Enter выбирает маршрут.

Закрытый селектор перестаёт показывать дефолт — это осознанно: дефолт
применяется сам и не требует постоянного отображения.

### 3. Иконка VTS в titlebar — как в Sidebar

В titlebar cluster VTS использует `PersonStanding`, в Sidebar — `Tv`.
Заменить на `Tv` для консистентности. Twitch иконки тоже сверить между
Sidebar (кастомный SVG) и titlebar (lucide `Twitch`): если визуально
отличаются — привести к одному виду.

### 4. Мигание иконки WebView в titlebar

Пользователь наблюдает периодическое мигание иконки WebView. Дедупликация
одинаковых статусов в `WebViewService::set_status` есть (webview/service.rs),
поэтому версии:

- статус реально колеблется Starting↔Running (reconnect-цикл сервера);
- фронтенд что-то переинициализирует composable;
- осталась видимой pulse-анимация `.connecting` при зависшем `starting`.

Расследовать по логам/событиям, починить причину, а не скрывать симптом.

### 5. Отступ между integration cluster и кнопками titlebar

Увеличить разделительный отступ примерно вдвое: сейчас
`.integration-gap { margin-left: 1.25rem }` → порядка `2.5rem`. Проверить
compact width: окно кнопок не должно переноситься или вытесняться.

### 6. Кнопка «Озвучить»

Синяя accent-заливка speak-btn визуально сильно выбивается из action bar.
Направление от пользователя: не перекрашивать в ещё один «яркий» вариант, а
снизить визуальную доминантность и закрепить позицию справа под полем ввода
(она уже там за `action-bar-spacer`). Варианты для пробы:

- тот же размер/форма, что у соседних action-кнопок, но заливка accent
  заменена на outline/тонированный вариант;
- оставить заливку только для состояния «доступно к отправке», dim — для
  disabled (как сейчас), без пульсации.

Решение фиксируется по результату ручной пробы, до реализации — эскиз.

### 7. Читаемость маршрута в minimal mode и унификация иконок

В minimal mode маршрут читается плохо (три иконки-назначения в 14px + chevron).
В full mode пользователь просит тоже показывать destinations-иконками вместо
текстового label. Итого:

- оба режима показывают destinations-иконки (`Volume2`/`Globe`/`Twitch`);
- в minimal mode повысить читаемость: чуть крупнее иконки или tooltip с
  полным label + shortcut (label уже есть в aria-label);
- при совпадении с дефолтом не дублировать звезду на закрытом селекторе.

## Порядок

1–3, 5 — механические, выполняются первыми. 4 — расследование. 6 — эскиз +
проба. 7 — после 2 (в одном дропдауне).

## Критерии завершения

- typing toggle — одна иконка в обоих режимах, состояние читается без tooltip;
- звёздочка-кнопка удалена, дефолт ставится звездой в списке, выбор и дефолт
  не мешают друг другу;
- VTS/Twitch иконки одинаковы в Sidebar и titlebar;
- иконка WebView не мигает при стабильном Running;
- отступ cluster↔кнопки заметно шире внутренних промежутков, compact не
  ломается;
- «Озвучить» не перетягивает внимание, позиция справа сохранена;
- маршрут читается в обоих режимах иконками destinations;
- npm test, npm run build, check-docs зелёные.

## Не входит

- изменение семантики маршрутов и префиксов (`!`, `!!`, `!t`);
- управление интеграциями кликом по titlebar-иконкам;
- per-message delivery outcomes.

# Перехват клавиш и снятие ограничения

## Цель

Расширить выбор клавиш для перехвата и дать пользователю возможность снять
ограничение списка отдельной сохраняемой галкой.

## Поведение

- Обычный режим: NumPad, F1–F24, Page Up, End, Page Down, Home и Insert.
- Галка **«Снять ограничение»** разрешает назначение остальных клавиш клавиатуры.
  Она выключена по умолчанию, в том числе при загрузке старых настроек.
- Под галкой отображается пояснение: **«Риск: система и программы не будут
  видеть нажатия назначенных клавиш, пока перехват включён.»**
- Перехватываются только назначенные клавиши при включённом перехвате.
  Снятие галки сохраняет дополнительные привязки, но делает их неактивными.
- В обычном режиме Escape отменяет запись. Со снятым ограничением Escape можно
  назначить; отмена выполняется кнопкой записи. Переход на другой экран отменяет
  запись и незавершённое назначение.
- Настройка сохраняется в `intercept.json`; ошибка сохранения не меняет режим
  в backend. На время сохранения новая запись недоступна.

## Реализация

Изменения внесены в панель перехвата, распознавание клавиш, Windows hook,
сохранение настроек и переводы RU/EN. Существующие привязки совместимы.

## Приёмка

Реализация готова к ручной проверке пользователем. Дополнительные проверки
записи, сборки и тесты остановлены по его просьбе. Итоговое состояние после
переименования галки и завершающих исправлений не проверено автоматически.

До остановки проверок прошли 65 Rust-тестов модуля soundpanel, `cargo check`,
17 тестов преобразования клавиш, сборка интерфейса и проверки локалей/IPC.
Это не подтверждает работу перехвата в готовом приложении.

Для завершения направления пользователь проверяет назначение Home/Insert,
произвольной клавиши и Escape, сохранение галки после перезапуска, отмену записи
при смене экрана и работу назначенных клавиш при включённом перехвате.

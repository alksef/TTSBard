# Язык интерфейса и внешние языковые пакеты

Интерфейс TTSBard поставляется на английском и русском. Дополнительный язык
добавляется файлом перевода без пересборки приложения: переводчик копирует
`en.json` соответствующей версии, меняет значения и кладёт файл в каталог
`locales`.

## Сменить язык интерфейса

1. Откройте **Настройки → Общие**.
2. В списке **Язык** выберите нужный язык. Названия показаны на самих языках:
   English, Русский и названия обнаруженных внешних пакетов.
3. Выбор сохраняется и применится при **следующем запуске** — текущие окна и
   трей до перезапуска остаются на прежнем языке. Приложение предупредит об этом.

Выбор языка не влияет на язык TTS, OCR, проверки орфографии, пользовательский
текст, имена голосов и уже сохранённые названия вкладок или наборов.

## Добавить свой перевод

1. Возьмите `en.json` той же версии, что и приложение. В установленной версии
   файл лежит в каталоге `locales` рядом с приложением (в ресурсах выпуска);
   в исходниках — в корне репозитория.
2. Скопируйте его и переименуйте по коду языка, например `de.json`. Код — это
   валидный тег вроде `de`, `pt-BR`, `zh-Hant`, `sr-Latn-RS`.
3. Откройте файл и исправьте:
   - `locale` — тот же код языка, что и имя файла (например `de`);
   - `name` — название языка на самом языке (например `Deutsch`);
   - значения внутри `messages` — переводите **только значения**, ключи и
     структуру не меняйте.
4. Сохраните файл в каталог `locales` (создайте его, если каталога ещё нет).
   На Windows приоритет каталогов такой:
   - `%APPDATA%\ttsbard\locales\` — пользовательские переводы, не затираются
     обновлением приложения (рекомендуется);
   - `locales\` рядом с приложением.
5. Перезапустите приложение и выберите новый язык в **Настройках → Общие**.

## Правила перевода

- Ключи вида `common.save`, `tray.quit`, `settings.title` — постоянные смысловые
  идентификаторы; их переносить и переименовывать нельзя.
- Параметры в фигурных скобках, например `{count}`, `{detail}`, `{name}`, —
  это подстановки. Их набор в переводе должен в точности совпадать с набором в
  английской строке; переставлять слова вокруг них можно.
- Не добавляйте неизвестные ключи и не удаляйте существующие — неполный пакет
  допустим (недостающие строки возьмутся из английского), лишние ключи
  игнорируются.
- Значение не может быть пустым. Файл должен оставаться корректным JSON
  с прежней структурой: `schemaVersion`, `locale`, `name`, `messages`.
- Не вносите в значения исполняемый HTML (`<script>` и т. п.) — такие строки
  отклоняются.
- Технические подробности от библиотек и сервисов (например тексты ошибок
  третьих сторон) могут остаться в исходном виде.

Один пакет покрывает все окна приложения и пункты нативного меню трея.
Если выбранный внешний пакет недоступен или повреждён, приложение использует
английский, а сохранённый выбор восстановится, когда файл снова станет
корректным.

# RUAccent: ударения и омографы

RUAccent — локальная модель для русского текста. Она расставляет ударения и
выбирает смысл омографов по контексту: например, различает `за́мок` и
`замо́к`. Модель запускается на компьютере пользователя; текст для этой
обработки никуда не отправляется.

Функция поддерживает синтез через Silero и Piper. При автоматическом режиме
исходный текст в редакторе не меняется: разметка применяется только к фразе,
которая уходит в синтез.

## Скачать и подготовить модель

Веса распространяет автор RUAccent на [Hugging Face
`ruaccent/accentuator`](https://huggingface.co/ruaccent/accentuator). Создайте
для модели отдельную папку:

```text
%APPDATA%\ttsbard\models\ruaccent\
```

### Скачать вручную

1. Откройте на Hugging Face вкладку
   [Files](https://huggingface.co/ruaccent/accentuator/tree/main).
2. Скачайте перечисленные ниже общие файлы из каталогов `dictionary` и `nn`,
   сохраняя их относительные пути.
3. Затем откройте
   [`nn/nn_omograph`](https://huggingface.co/ruaccent/accentuator/tree/main/nn/nn_omograph),
   выберите **один** вариант модели, например `tiny`, и скачайте его файлы
   отдельно в одноимённую папку. Не нужно скачивать все варианты.

После этого структура должна выглядеть так:

```text
%APPDATA%\ttsbard\models\ruaccent\
  dictionary/
    accents.json.gz
    omographs.json.gz
    yo_words.json.gz
    yo_homographs.json.gz
  nn/
    nn_accent/
      model.onnx
      config.json
      vocab.txt
    nn_omograph/
      tiny/                       ← один выбранный вариант
        model.onnx
        tokenizer.json
    nn_stress_usage_predictor/
      model.onnx
      config.json
      tokenizer.json
    nn_yo_homograph_resolver/
      model.onnx
      config.json
      tokenizer.json
```

Не кладите `nn` и `dictionary` в дополнительную вложенную папку. TTSBard
сам найдёт каждый полный вариант в `nn/nn_omograph`. Затем перезапустите
TTSBard.

### Скачать через Python (необязательно)

Вместо ручного выбора файлов можно установить Python-библиотеку RUAccent и
выполнить её штатный загрузчик. Он скачает общие файлы и вариант `tiny` в
нужную папку:

```powershell
python -m pip install ruaccent
python -c "from ruaccent import RUAccent; RUAccent().load(omograph_model_size='tiny', use_dictionary=True, workdir=r'$env:APPDATA\ttsbard\models\ruaccent')"
```

Python не нужен для работы TTSBard: приложение использует встроенный native
runtime. Его требуется установить лишь для этого альтернативного способа
скачать файлы.

## Включить автоматическую обработку

1. Откройте **Настройки → Омографы и ударения**.
2. Выберите найденную **модель RUAccent**.
3. Нажмите кнопку загрузки справа от списка и дождитесь статуса **«Готова»**.
4. Включите **«Автоматически расставлять ударения»**. Эта настройка применяется
   к каждому сообщению перед синтезом и также разрешает омографы.

По умолчанию модель не загружается при синтезе автоматически. Чтобы не нажимать
кнопку после каждого запуска приложения, включите **«Загружать при запуске»**;
запуск может занять немного больше времени. Если загрузка завершилась ошибкой,
проверьте файлы и нажмите кнопку повторной попытки рядом со списком.

Если модель не видна после перезапуска, проверьте, что
папки `nn` и `dictionary` лежат прямо в `ruaccent`, без лишнего уровня
вложенности, а у выбранного варианта есть `model.onnx` и `tokenizer.json`.

## Обработать только нужную фразу

Автоматический режим можно оставить выключенным. В редакторе откройте меню
`…` и выберите **«Расставить ударения»**, либо нажмите `Ctrl+U`. Комбинация
настраивается в **Горячие клавиши → Редактор**.

Эта команда расставляет ударения и выбирает вариант омографа по контексту в
текущем тексте редактора, чтобы результат можно было проверить перед отправкой.
Она требует выбранной модели со статусом **«Готова»**, но не требует включать
автоматическую обработку для всех сообщений.

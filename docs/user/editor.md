# Редактор, маршруты и горячие клавиши

Основные действия после первой настройки TTS. Для первого запуска начните с [руководства](./guide.md).

## Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl + Shift + F2` | Показать звуковую панель |
| `Ctrl + Shift + F3` | Показать главное окно (поверх всех, для фокуса) |
| `Ctrl + Shift + F4` | Пауза / продолжение воспроизведения |
| `Ctrl + Shift + F5` | Остановить воспроизведение |
| `Ctrl + Shift + F6` | Повторить последнюю фразу |
| `Ctrl + Shift + F7` | Показать Playback Control |
| `Ctrl + Shift + P` | Выделить область экрана для однократного OCR |
| `Ctrl + F` | Вернуть фокус предыдущему окну |

## Настройка горячих клавиш

Приложение поддерживает кастомизацию горячих клавиш для всех основных функций:

1. Откройте панель **"Горячие клавиши"** в боковом меню
2. Выберите функцию для настройки
3. Нажмите кнопку записи и нажмите нужную комбинацию клавиш
4. Сохраните изменения

**Доступные для настройки функции:**
- Звуковая панель (по умолчанию: `Ctrl+Shift+F2`)
- Главное окно (по умолчанию: `Ctrl+Shift+F3`)
- Управление воспроизведением и окно Playback Control
- Возврат фокуса предыдущему окну

### Локальные сочетания редактора

В панели горячих клавиш есть отдельный блок **«Редактор»**. Эти сочетания
работают только в CodeMirror и на панели вкладок: они не регистрируются как
системные сочетания Windows. Любое из них можно переназначить или отключить
пустой привязкой.

| По умолчанию | Действие |
|---|---|
| `Ctrl+E` | Открыть исправление для слова под курсором |
| `Ctrl+Enter` | Озвучить и продолжить работу в редакторе |
| `Alt+Enter` | Озвучить, инвертировав настройку очистки текста (см. ниже) |
| `Ctrl+Alt+Enter` | Озвучить, сохранить текст и остаться в редакторе |
| `F7` / `Shift+F7` | Следующая / предыдущая орфографическая ошибка |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая / предыдущая вкладка |
| `Ctrl+R` | Следующий маршрут фразы |
| `Ctrl+T` | Передача набора текста (WebView / VTube Studio) вкл/выкл |
| `Ctrl+W` | Режим быстрого редактора |
| `Ctrl+H` | История фраз |
| `Ctrl+U` | Разово расставить ударения |

Сочетания сопоставляются по физической клавише, поэтому буквенные привязки
одинаково работают в русской и английской раскладках. Обычный `Enter` сохраняет
выбранное действие быстрого редактора: свернуть окно, вернуть фокус или остаться
в нём. `Ctrl+Enter` всегда оставляет окно открытым и возвращает фокус в редактор.

Панель редактора показывает фактическую семантику отправки рядом с кнопкой
«Озвучить»: в полном режиме рядом с кнопкой читается краткая подсказка
`Enter → <действие> · <привязка> → отправить и продолжить`. В компактном режиме
кнопка сворачивается до иконки, а подсказка доступна в её tooltip и
`aria-label`. `Ctrl+Enter` не отключает и не отменяет настройку быстрого
редактора: следующий обычный `Enter` снова применит настроенное действие.

### Шрифт и размер текста

В **«Настройки → Редактор»** верхняя плашка позволяет выбрать шрифт и размер
текста от **12 до 32 px**. Под полями показан образец. Доступны «По умолчанию»,
«Системный», Arial, Georgia и Consolas; исходный размер — **16 px**.
Выбор применяется сразу ко всем рабочим вкладкам, включая компактный режим,
и сохраняется между запусками. Текст и история отмены сохраняются.
Во время записи поля кратко недоступны; при ошибке можно повторить выбор.

### Сохранение текста после отправки

По умолчанию после успешной отправки редактор очищается. В настройках
(«Настройки → Редактор») есть галка **«Не очищать текст после отправки»**:
отправленный текст остаётся в редакторе, чтобы поправить опечатку и
переспросить, или отправить ту же фразу повторно, а затем быстро стереть
через `Ctrl+A`.

Клавиши очистки и поведения окна — независимые оси:

- **`Alt+Enter`** разово инвертирует настройку очистки: при выключенной
  галке — отправить и сохранить текст; при включённой — отправить и
  стереть. Действие быстрого редактора (свернуть окно / вернуть фокус)
  при этом применяется как обычно.
- **`Ctrl+Alt+Enter`** всегда отправляет, сохраняет текст и оставляет окно
  открытым с фокусом в редакторе — независимо от быстрого режима.

Повторная отправка того же текста тем же голосом и провайдером (при
неизменных аудио-эффектах) не обращается к TTS-провайдеру: озвучивание
берётся из локального кеша фраз и не расходует лимиты.

### Автодополнение

Редактор предлагает слова из персонального словаря, продолжения из истории
фраз, AI-продолжения и подстановки быстрой вставки. Частота использования
остаётся внутренней частью ранжирования и не показывается рядом с вариантами.

Общий показ подсказок можно выключить в **Настройки → Редактор → Проверка и
подсказки** галкой **«Показывать подсказки автодополнения»**. При выключенной
галке список не открывается и редактор не запрашивает локальные или AI-варианты,
но успешно отправленные фразы по-прежнему пополняют локальную историю. После
повторного включения подсказки учитывают статистику, накопленную за это время.

Настройка **«AI-продолжение текста (автодополнение)»** управляет только
AI-источником и не отменяет общий переключатель: AI-варианты появляются, лишь
когда включены обе настройки. Ручная команда **«AI: дописать»** описана в
[руководстве по AI-функциям](./ai-text.md).

### История фраз

Откройте историю сочетанием `Ctrl+H`. В списке фраз может отображаться текст с
маркерами ударений, который был фактически передан TTS-провайдеру. При выборе
«Заменить» или «Добавить» в редактор возвращается чистый текст без технических
маркеров Silero и Piper; его можно свободно отредактировать и отправить снова.

## Структура приложения

### Боковая панель (Sidebar)

Главное окно содержит боковую панель с навигацией по разделам:

**ГЛАВНОЕ:**
- **Текст** — основной редактор для ввода и озвучивания текста
- **TTS** — настройка TTS-провайдеров и голосов
- **Аудио** — настройка устройств вывода и громкости

**Дополнительно:**
- **Быстрая вставка** — настройка автозамены и пресетов
- **WebView** — настройка сервера для OBS
- **Twitch** — интеграция с Twitch чатом
- **VTube Studio** — подключение и выбор действия при наборе текста
- **OCR** — настройка локального распознавания текста с экрана
- **Входящий сервер** — приём текста из локальных приложений для озвучивания
- **Настройки** — общие настройки приложения
- **Горячие клавиши** — настройка комбинаций клавиш

SoundPanel не является разделом сайдбара: это отдельное плавающее окно,
которое открывается кнопкой в заголовке или назначенной глобальной комбинацией.

### Статусы интеграций в заголовке

В правой части заголовка окна находятся три постоянные иконки: WebView,
Twitch и VTube Studio. Они показывают фактическую готовность каждой
интеграции, а не выбранный маршрут текущей фразы:

- **серый** — интеграция выключена, не настроена, остановлена вручную или ещё
  подключается;
- **тускло-зелёный** — интеграция фактически работает (сервер запущен,
  соединение установлено, VTube Studio авторизован);
- **красный** — интеграция должна работать, но перешла в ошибку.

Наведение курсора показывает точную формулировку состояния, включая текст
ошибки. Ручная остановка интеграции всегда возвращает серый цвет. Иконки
являются индикаторами и не реагируют на клик.

### Компактный режим

Кнопка в правом нижнем углу редактора сворачивает окно до одного поля
ввода (компактный режим). Клавиша `Ctrl+M` переключает компактный и
обычный режим; это локальная клавиша — она работает при фокусе в главном
окне и не регистрируется в системе (переназначается в разделе
«Основное окно» панели горячих клавиш).

В компактном режиме высота окна меняется перетаскиванием нижней границы
поля ввода (300–500 px, сохраняется). При открытой истории фраз редактор
сохраняет минимальную высоту, а список скроллится.

Галка **«Запускать в компактном режиме»** (Настройки → Общее) открывает
приложение сразу в компактном виде.

### Сворачивание, трей и выход

Приложение продолжает работать в фоне: сворачивание не останавливает
озвучивание и фоновые интеграции.

- **Свернуть.** Кнопка «Свернуть» в заголовке и системные способы
  сворачивания оставляют окно на панели задач; значок в трее остаётся.
  Галка **«Скрывать с панели задач при сворачивании»** (Настройки → Общее)
  выключена по умолчанию. Если её включить, при сворачивании окно
  полностью скрывается и остаётся только значок в трее. Настройка
  применяется к следующему сворачиванию и сохраняется между запусками.
  Приложение продолжает работать. Вернуть окно можно через значок в трее или повторным запуском.
- **Вернуть окно.** Клик по значку в трее, команда «Показать главное
  окно» в меню трея или повторный запуск приложения через «Пуск»/ярлык
  показывают и активируют то же окно с прежним текстом и очередью речи.
  Если после отключения монитора окно оказалось за пределами доступных
  экранов или видна лишь небольшая его часть, оно переносится в центр
  основного монитора. Такая же проверка выполняется при старте приложения;
  восстановленная позиция сохраняется.
- **Выход.** Кнопки закрытия в заголовке нет — сворачивание не завершает
  приложение. Полностью выйти: `Alt+F4` в главном окне, системная команда
  закрытия окна или «Выход» в меню трея. Все способы проходят штатное
  завершение с сохранением данных.
- **Одна копия.** Повторный запуск в том же сеансе Windows не создаёт вторую работающую копию:
  новый процесс сообщает работающему приложению показать окно и
  завершается.

## Обработка текста

Перед синтезом применяются следующие базовые операции; AI-коррекция и RUAccent описаны в отдельных руководствах:

1. **Управление отправкой** — префиксы `!` и `!!` контролируют маршрутизацию
2. **Быстрая вставка** — пресеты `\ключ` и `%юзернейм` для замены текста
3. **Конвертация чисел** — числа преобразуются в текст с согласованием рода

### Управление отправкой

Используйте префиксы в начале текста для контроля отправки в Twitch и WebView:

| Префикс | Описание | Пример | Twitch | WebView | TTS |
|---------|----------|--------|--------|---------|-----|
| Без префикса | Выбранный маршрут вкладки | `Привет всем` | По маршруту | По маршруту | По маршруту |
| `!` | Голос + WebView | `!Привет` | ❌ | ✅ | ✅ |
| `!!` | Только TTS | `!!Привет` | ❌ | ❌ | ✅ |
| `!t` | Только Twitch | `!t Привет` | ✅ | ❌ | ❌ |

`!t` распознаётся только как отдельное слово в начале строки: `!t` в конце
ввода или `!t сообщение`. Фраза `!thanks` сохраняет старое поведение
одиночного `!` (голос + WebView без Twitch).

**Примеры использования:**
```
!Только для OBS — озвучить, но не в Twitch
!!Локальное сообщение — только для TTS
!t Сообщение только в чат Twitch, без озвучивания
Обычный текст — использовать выбранный маршрут вкладки
```

### Маршрут фразы

Действия над текстом включают **селектор маршрута** — он показывает, куда
уйдёт текущая фраза, и обновляется сразу при вводе префикса. Маршрут можно
выбрать и мышью: селектор перепишет ведущий префикс сам, запоминать синтаксис
не обязательно.

- «Везде» — голос + WebView + Twitch;
- «Без Twitch» — голос + WebView (`!`);
- «Только голос» (`!!`);
- «Только Twitch» (`!t`) — доступен только при подключённом Twitch; кнопка
  отправки меняет подпись на «Отправить в Twitch», задача озвучивания не
  создаётся.

Кнопка со звездой сохраняет текущий маршрут как маршрут по умолчанию: пустой
редактор и новые вкладки начнут с него, после успешной отправки маршрут
вкладки возвращается к значению по умолчанию. Ошибка доставки (например,
отключённый Twitch) не очищает текст и не сбрасывает маршрут — фразу можно
исправить и отправить снова.

### Передача набора текста

Переключатель «Передавать набор» рядом с селектором маршрута управляет
публикацией transient-состояния набора текста в WebView и VTube Studio. При
выключении во время набора сначала отправляется завершающее состояние
«набор окончен», новые оповещания подавляются. Настройка сохраняется и
действует в полном и компактном режимах.

### Быстрая вставка

| Синтаксис | Описание | Пример | Результат |
|-----------|----------|--------|----------|
| `\ключ` | Замена текста по коду | `\name` + пробел | Александр |
| `%юзернейм` | Замена имени пользователя | `%admin` + пробел | Администратор |

**Настройка:** Панель "Быстрая вставка" → Списки замен / Список юзернеймов

### Конвертация чисел

Числа автоматически преобразуются в текст с согласованием рода следующего слова:

| Ввод | Результат |
|------|-----------|
| `У меня 5 яблок` | `У меня пять яблок` |
| `1 книга` | `одна книга` |
| `2 книги` | `две книги` |
| `5 книг` | `пять книг` |
| `123` | `сто двадцать три` |
| `-10` | `минус десять` |

**Правила:**
- Числа `1` и `2-4` согласуются с родом следующего слова
- Числа `5+` используют множественное число

## Проверка орфографии

Редактор поддерживает офлайн-проверку орфографии русского языка. Проверка
выполняется локально, без отправки текста внешним сервисам.

**Включение:** **Настройки → Редактор → Проверка и подсказки** → переключатель
**«Проверка орфографии (офлайн)»**.

**Волнистое подчёркивание:** слова, отсутствующие в словаре, постоянно
подчёркиваются красной волнистой линией.

**Контекстное меню:** правая кнопка мыши на подчёркнутом слове открывает меню с
вариантами исправления (до пяти вариантов). Для слова под курсором меню также
можно открыть локальным сочетанием `Ctrl+E`. Стрелки `↑`/`↓` перемещают выбор
по вариантам, `Enter` применяет выбранный вариант, а `Escape` закрывает меню.
Выбор suggestion заменяет только конкретное вхождение, не затрагивая другие
одинаковые опечатки в тексте. Меню также закрывается кликом снаружи или
переключением вкладки.

Сочетания `F7` и `Shift+F7` переходят к следующей и предыдущей найденной
орфографической ошибке. Они работают только внутри редактора и используют
текущие диагностики.

Если словарь не загрузился (например, отсутствуют файлы словаря), под
редактором отображается сообщение «словарь недоступен», а подчёркивание не
выполняется. После устранения проблемы проверка восстанавливается автоматически
при следующем вводе текста.

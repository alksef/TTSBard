# TTSBard - Руководство пользователя

> **TTS-приложение для общения с минимальным отвлечением от работы**
> Версия: 0.21.0
> Платформа: Windows 10/11
> Дата обновления: 2026-08-15

---

## Краткое описание

**TTSBard** — это приложение для синтеза речи (Text-to-Speech), которое работает в фоновом режиме и доступно мгновенно по горячей клавише в любом приложении. Поддерживает 4 TTS-провайдера: OpenAI TTS, Silero Bot (Telegram), Fish Audio и Local TTS.

---

## Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl + Shift + F2` | Показать звуковую панель |
| `Ctrl + Shift + F3` | Показать главное окно (поверх всех, для фокуса) |
| `Ctrl + Shift + F4` | Пауза / продолжение воспроизведения |
| `Ctrl + Shift + F5` | Остановить воспроизведение |
| `Ctrl + Shift + F6` | Повторить последнюю фразу |
| `Ctrl + Shift + F7` | Показать Playback Control |
| `Ctrl + F` | Вернуть фокус предыдущему окну |

## Настройка горячих клавиш

Приложение поддерживает кастомизацию горячих клавиш для всех основных функций:

1. Откройте панель **"Горячие клавиши"** в боковом меню
2. Выберите функцию для настройки
3. Нажмите кнопку записи и нажмите нужную комбинацию клавиш
4. Сохраните изменения

**Доступные для настройки функции:**
- Звуковая панель (по умолчанию: `Ctrl+Shift+F2`)
- Главное окно (по умолчанию: `Ctrl+Shift+F3`)
- Управление воспроизведением и окно Playback Control
- Возврат фокуса предыдущему окну

### Локальные сочетания редактора

В панели горячих клавиш есть отдельный блок **«Редактор»**. Эти сочетания
работают только в CodeMirror и на панели вкладок: они не регистрируются как
системные сочетания Windows. Любое из них можно переназначить или отключить
пустой привязкой.

| По умолчанию | Действие |
|---|---|
| `Ctrl+E` | Открыть исправление для слова под курсором |
| `Ctrl+Enter` | Озвучить и продолжить работу в редакторе |
| `F7` / `Shift+F7` | Следующая / предыдущая орфографическая ошибка |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая / предыдущая вкладка |

Сочетания сопоставляются по физической клавише, поэтому буквенные привязки
одинаково работают в русской и английской раскладках. Обычный `Enter` сохраняет
выбранное действие быстрого редактора: свернуть окно, вернуть фокус или остаться
в нём. `Ctrl+Enter` всегда оставляет окно открытым и возвращает фокус в редактор.

Панель редактора показывает фактическую семантику отправки рядом с кнопкой
«Озвучить»: в полном режиме рядом с кнопкой читается краткая подсказка
`Enter → <действие> · <привязка> → отправить и продолжить`. В компактном режиме
кнопка сворачивается до иконки, а подсказка доступна в её tooltip и
`aria-label`. `Ctrl+Enter` не отключает и не отменяет настройку быстрого
редактора: следующий обычный `Enter` снова применит настроенное действие.

## Структура приложения

### Боковая панель (Sidebar)

Главное окно содержит боковую панель с навигацией по разделам:

**ГЛАВНОЕ:**
- **Текст** — основной редактор для ввода и озвучивания текста
- **Руководство** — справочная информация и горячие клавиши
- **TTS** — настройка TTS-провайдеров и голосов
- **Аудио** — настройка устройств вывода и громкости

**Дополнительно:**
- **Быстрая вставка** — настройка автозамены и пресетов
- **WebView** — настройка сервера для OBS
- **Twitch** — интеграция с Twitch чатом
- **VTube Studio** — подключение и выбор действия при наборе текста
- **Настройки** — общие настройки приложения
- **Горячие клавиши** — настройка комбинаций клавиш

SoundPanel не является разделом сайдбара: это отдельное плавающее окно,
которое открывается кнопкой в заголовке или назначенной глобальной комбинацией.

## TTS провайдеры

Приложение поддерживает 4 TTS-провайдера:

### OpenAI TTS
- 6 естественных голосов: alloy, echo, fable, onyx, nova, shimmer
- Настройка скорости (0.25-4.0)
- Поддержка прокси
- Требуется API ключ

### Silero Bot (Telegram)
- Интеграция с Telegram ботом @SileroBot
- Авторизация через телефон
- Работает без API ключа
- Выбор голоса через бота

Таймаут ожидания ответа и задержку между повторными скачиваниями можно изменить
вручную в `settings.json`. Путь к файлу, допустимые диапазоны и JSON-пример
приведены в разделе [«Ручная настройка Silero»](./silero-settings.md).

### Fish Audio
- Высококачественный синтез речи
- Настройка формата аудио (mp3, wav, ogg)
- Регулировка temperature и sample rate
- Поддержка прокси
- Требуется API ключ

### Local TTS
- Режим "Locally Hosted" из TTS Voice Wizard
- HTTP запросы к локальному серверу (TITTS.py или совместимый)
- Работает без интернета
- URL по умолчанию: `http://127.0.0.1:8124`

## Обработка текста

Автоматическая обработка текста перед отправкой в TTS выполняется в три этапа:

1. **Управление отправкой** — префиксы `!` и `!!` контролируют маршрутизацию
2. **Быстрая вставка** — пресеты `\ключ` и `%юзернейм` для замены текста
3. **Конвертация чисел** — числа преобразуются в текст с согласованием рода

### Управление отправкой

Используйте префиксы в начале текста для контроля отправки в Twitch и WebView:

| Префикс | Описание | Пример | Twitch | WebView | TTS |
|---------|----------|--------|--------|---------|-----|
| Без префикса | Отправить везде | `Привет всем` | ✅ | ✅ | ✅ |
| `!` | Только WebView | `!Привет` | ❌ | ✅ | ✅ |
| `!!` | Только TTS | `!!Привет` | ❌ | ❌ | ✅ |
| `!t` | Только Twitch | `!t Привет` | ✅ | ❌ | ❌ |

`!t` распознаётся только как отдельное слово в начале строки: `!t` в конце
ввода или `!t сообщение`. Фраза `!thanks` сохраняет старое поведение
одиночного `!` (голос + WebView без Twitch).

**Примеры использования:**
```
!Только для OBS — озвучить, но не в Twitch
!!Локальное сообщение — только для TTS
!t Сообщение только в чат Twitch, без озвучивания
Обычный текст — отправить везде
```

### Маршрут фразы

Действия над текстом включают **селектор маршрута** — он показывает, куда
уйдёт текущая фраза, и обновляется сразу при вводе префикса. Маршрут можно
выбрать и мышью: селектор перепишет ведущий префикс сам, запоминать синтаксис
не обязательно.

- «Везде» — голос + WebView + Twitch (без префикса);
- «Без Twitch» — голос + WebView (`!`);
- «Только голос» (`!!`);
- «Только Twitch» (`!t`) — доступен только при подключённом Twitch; кнопка
  отправки меняет подпись на «Отправить в Twitch», задача озвучивания не
  создаётся.

Кнопка со звездой сохраняет текущий маршрут как маршрут по умолчанию: пустой
редактор и новые вкладки начнут с него, после успешной отправки маршрут
вкладки возвращается к значению по умолчанию. Ошибка доставки (например,
отключённый Twitch) не очищает текст и не сбрасывает маршрут — фразу можно
исправить и отправить снова.

### Передача набора текста

Переключатель «Передавать набор» рядом с селектором маршрута управляет
публикацией transient-состояния набора текста в WebView и VTube Studio. При
выключении во время набора сначала отправляется завершающее состояние
«набор окончен», новые оповещания подавляются. Настройка сохраняется и
действует в полном и компактном режимах.

### Быстрая вставка

| Синтаксис | Описание | Пример | Результат |
|-----------|----------|--------|----------|
| `\ключ` | Замена текста по коду | `\name` + пробел | Александр |
| `%юзернейм` | Замена имени пользователя | `%admin` + пробел | Администратор |

**Настройка:** Панель "Быстрая вставка" → Списки замен / Список юзернеймов

### Конвертация чисел

Числа автоматически преобразуются в текст с согласованием рода следующего слова:

| Ввод | Результат |
|------|-----------|
| `У меня 5 яблок` | `У меня пять яблок` |
| `1 книга` | `одна книга` |
| `2 книги` | `две книги` |
| `5 книг` | `пять книг` |
| `123` | `сто двадцать три` |
| `-10` | `минус десять` |

**Правила:**
- Числа `1` и `2-4` согласуются с родом следующего слова
- Числа `5+` используют множественное число

## AI-коррекция и продолжение текста

## Проверка орфографии

Редактор поддерживает офлайн-проверку орфографии русского языка. Проверка
выполняется локально, без отправки текста внешним сервисам.

**Включение:** панель **Настройки** → раздел **Editor** → переключатель
«Проверка орфографии».

**Волнистое подчёркивание:** слова, отсутствующие в словаре, постоянно
подчёркиваются красной волнистой линией.

**Контекстное меню:** правая кнопка мыши на подчёркнутом слове открывает меню с
вариантами исправления (до пяти вариантов). Для слова под курсором меню также
можно открыть локальным сочетанием `Ctrl+E`. Стрелки `↑`/`↓` перемещают выбор
по вариантам, `Enter` применяет выбранный вариант, а `Escape` закрывает меню.
Выбор suggestion заменяет только конкретное вхождение, не затрагивая другие
одинаковые опечатки в тексте. Меню также закрывается кликом снаружи или
переключением вкладки.

Сочетания `F7` и `Shift+F7` переходят к следующей и предыдущей найденной
орфографической ошибке. Они работают только внутри редактора и используют
текущие диагностики.

Если словарь не загрузился (например, отсутствуют файлы словаря), под
редактором отображается сообщение «словарь недоступен», а подчёркивание не
выполняется. После устранения проблемы проверка восстанавливается автоматически
при следующем вводе текста.

## Звуковая панель (Саунпад)

SoundPanel — отдельное плавающее окно с сеткой `A–Z` и `0–9`. Оно объединяет
воспроизведение, назначение файлов и управление слоями; отдельного пункта
«Звуковая панель» в боковом меню больше нет.

### Использование

1. Нажмите `Ctrl+Shift+F2` или кнопку SoundPanel в заголовке главного окна.
2. Переключитесь в config кнопкой-шестерёнкой или `Ctrl+B`.
3. Нажмите ячейку сетки и выберите аудиофайл с описанием.
4. Вернитесь в runtime через `Ctrl+B`.
5. Нажмите назначенную клавишу, `Enter` на выбранной ячейке или кликните по ней.

### Возможности

- До 36 привязок на слой: `A–Z` и `0–9`.
- Форматы: MP3, WAV, OGG, FLAC, M4A, AAC и WMA.
- Слои переключаются селектом, `PageUp` / `PageDown` или напрямую `F1–F12`.
- Стрелки перемещают выбор по двумерной сетке, `Enter` активирует ячейку.
- Гвоздик в заголовке закрепляет панель и сохраняет состояние.
- Звуки используют те же выбранные динамики и виртуальный микрофон, что и TTS,
  с отдельной громкостью каждого канала.
- Быстрые нажатия воспроизводятся FIFO без наложения; эта очередь независима
  от очереди речи и не прерывает TTS.
- Возврат фокуса в предыдущее окно до начала воспроизведения
- Одинаковая политика для клика, Enter, физической клавиши, `Escape` и потери
  фокуса: без закрепления панель скрывается, с закреплением остаётся открытой.
- Перетаскивание закреплённой панели за заголовок; кнопка `×` всегда закрывает окно
- Цвет может наследоваться от главного окна, а прозрачность всегда регулируется
  отдельно в **Настройки → Интерфейс**.

### Горячие клавиши

- `Ctrl+Shift+F2` — показать и сфокусировать панель
- `Ctrl+B` — переключить runtime/config
- `A–Z`, `0–9` — запустить звук или настроить ячейку
- `F1–F12` — выбрать слой по номеру; отсутствующий слой игнорируется
- `PageUp` / `PageDown` — предыдущий/следующий слой

Полный контракт и таблица управления приведены в отдельном
[руководстве по SoundPanel](./soundpanel.md).

## Интеграции

### WebView сервер (OBS)

Отображение текста в реальном времени в OBS Studio или браузере через Server-Sent Events (SSE).

**Настройка:**
1. Включите WebView сервер в настройках (по умолчанию порт 10100)
2. Добавьте Browser Source в OBS: `http://localhost:10100`
3. Отправьте текст в TTS — текст появится в OBS мгновенно

**Возможности:**
- SSE (Server-Sent Events) для real-time обновлений
- Настраиваемый порт и bind address (0.0.0.0 / 127.0.0.1)
- Полная кастомизация HTML/CSS шаблонов
- Токен-аутентификация для внешних подключений
- UPnP — автоматический проброс портов на роутере

### Twitch Chat

Отправка TTS сообщений в Twitch чат для дублирования.

**Настройка:**
1. Создайте Twitch бота на [twitchtokengenerator.com](https://twitchtokengenerator.com)
2. Скопируйте OAuth токен со страницы (только сам токен, без префикса)
3. Введите данные в настройках Twitch Chat
4. Нажмите Start для подключения к чату

**Поля настроек:**
- **Username** — имя бота (без @)
- **Token** — только токен (без `oauth:`)
- **Channel** — канал (имя или URL)

### VTube Studio

TTSBard передаёт состояние набора текста в VTube Studio тремя способами:

- **Параметр VTS** — собственный INPUT TTSBard получает значение `1` во время набора и `0` после его окончания;
- **Горячие клавиши** — запускаются выбранные Hotkey для начала и окончания набора;
- **Предмет сцены** — выбранный предмет показывается во время набора и скрывается после него.

Действие можно редактировать только при живом подключении. TTSBard самостоятельно создаёт INPUT перед использованием, безопасно заменяет его при переименовании и сохраняет настройки после отключения. Подробная настройка INPUT/OUTPUT, Hotkeys, предмета сцены и диагностика приведены в [руководстве по VTube Studio](../integrations/vtube-studio.md).

## Первая настройка

### Выбор TTS провайдера

При первом запуске выберите один из 4 доступных TTS-провайдеров:

**OpenAI TTS:**
1. Получите API ключ на https://platform.openai.com/api-keys
2. Скопируйте ключ (начинается с `sk-`)
3. Откройте панель **TTS** → вкладка **OpenAI**
4. Вставьте ключ и нажмите **"Сохранить настройки"**

**Silero Bot:**
1. Откройте панель **TTS** → вкладка **Silero**
2. Нажмите **"Подключить Telegram"**
3. Следуйте инструкциям в открывшемся окне
4. Выберите голос через бота @SileroBot

**Fish Audio:**
1. Получите API ключ на сайте Fish Audio
2. Откройте панель **TTS** → вкладка **Fish Audio**
3. Вставьте ключ и настройте параметры
4. Нажмите **"Сохранить настройки"**

**Local TTS:**
1. Убедитесь, что локальный TTS сервер запущен (TITTS.py)
2. Откройте панель **TTS** → вкладка **Local**
3. Укажите URL сервера (по умолчанию `http://127.0.0.1:8124`)
4. Нажмите **"Сохранить"**

## Системные требования

### Минимальные требования

- **ОС:** Windows 10/11 (64-bit)
- **Процессор:** Intel Core i3 или эквивалент
- **Память:** 4 GB RAM
- **Место на диске:** 100 MB

- **ОС:** Windows 11 (64-bit)
- **Процессор:** Intel Core i5 или эквивалент
- **Память:** 8 GB RAM
- **Место на диске:** 500 MB
- **Интернет:** Стабильное подключение

### Примечания

- Для **Local TTS** интернет не требуется
- Для работы с правами Administrator могут потребоваться дополнительные настройки
- Назначенные Numpad/F-key действия не перехватываются из приложений с правами
  Administrator, если TTSBard запущен без повышения прав
- Не может блокировать `Ctrl+Alt+Del` (Secure Desktop)

## Возможные проблемы

### Горячие клавиши не работают

**Причина:** Хоткей может быть занят другим приложением

**Решение:**
1. Закройте приложения, которые могут использовать эти клавиши
2. Или настройте другие комбинации в панели **"Горячие клавиши"**

### TTS не озвучивает текст

**Проверьте:**
1. Выбран ли TTS-провайдер в панели **TTS**
2. Введён ли API ключ (для OpenAI, Fish Audio)
3. Подключён ли Silero Bot (для Silero)
4. Запущен ли локальный сервер (для Local TTS)

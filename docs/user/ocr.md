# OCR: модели и распознавание экрана

OCR в TTSBard однократно распознаёт выделенную область экрана и передаёт текст
во **«Входящие»**. Распознавание выполняется локально; перевод не выполняется.
Озвучивание использует выбранный TTS-провайдер, который может быть облачным.

Встроенный OCR не требует LunaTranslator и запуска входящего HTTP-сервера.
Если текст извлекает LunaTranslator, используйте [его интеграцию](../integrations/lunatranslator/README.md).

## Какой пакет нужен

TTSBard поддерживает семейство **PP-OCRv5** в ONNX-формате. Пакет состоит из
детектора текстовых областей, распознавателя, словаря символов и `manifest.json`.
Произвольный файл ONNX или модель Piper для этого не подходит.

Ниже приведена установка пакета **eSlav PP-OCRv5 Mobile**. В его манифесте
заявлены русский и английский языки. Детектор `ch_PP-OCRv5_det_mobile` находит области текста, а распознаватель
`eslav_PP-OCRv5_rec_mobile` читает символы по соответствующему словарю.

## Получить файлы

1. В TTSBard откройте **Настройки → Общие → Папки** и нажмите **«Открыть»**
   у **«Данные программы»**. В открывшемся Проводнике создайте подпапки
   `models\ocr\eslav-ppocrv5-mobile`. Кнопка открывает текущую папку данных,
   в том числе выбранную пользователем вместо стандартной.
2. Скачайте три файла из официального репозитория RapidAI/RapidOCR на ModelScope
   и сохраните их под указанными именами в этой папке:

| Сохранить как | Источник |
|---|---|
| `det.onnx` | [ch_PP-OCRv5_det_mobile.onnx](https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/master/onnx/PP-OCRv5/det/ch_PP-OCRv5_det_mobile.onnx) |
| `rec.onnx` | [eslav_PP-OCRv5_rec_mobile.onnx](https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/master/onnx/PP-OCRv5/rec/eslav_PP-OCRv5_rec_mobile.onnx) |
| `dict.txt` | [ppocrv5_eslav_dict.txt](https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/master/paddle/PP-OCRv5/rec/eslav_PP-OCRv5_rec_mobile/ppocrv5_eslav_dict.txt) |

3. Создайте рядом файл **`manifest.json`** с этим содержимым:

```json
{
  "id": "eslav-ppocrv5-mobile",
  "display_name": "eSlav PP-OCRv5 Mobile",
  "languages": ["ru", "en"],
  "family": "pp_ocr_v5",
  "det_file": "det.onnx",
  "rec_file": "rec.onnx",
  "dict_file": "dict.txt"
}
```

Сохраните JSON в UTF-8. В Блокноте выберите тип **«Все файлы»**, чтобы не получить
`manifest.json.txt`. Словарь скачивайте как файл, сохраняя порядок строк;
не редактируйте его вручную.

Все три ссылки проверены на доступность 4 сентября 2026 года. Они используют
ветку `master`, поэтому upstream может обновлять содержимое. Для повторяемой
установки сохраняйте комплект файлов вместе; не смешивайте распознаватель
одной версии со словарём другой.

## Проверить расположение

В стандартном корне должно получиться ровно так:

```text
%LOCALAPPDATA%\ttsbard\models\ocr\
  eslav-ppocrv5-mobile\
    manifest.json
    det.onnx
    rec.onnx
    dict.txt
```

TTSBard просматривает только непосредственные подпапки `ocr`. Имя подпапки
должно совпадать с `id` в манифесте. Файлы прямо внутри `ocr` или дополнительный
уровень `eslav-ppocrv5-mobile\eslav-ppocrv5-mobile` обнаружены не будут.

Для другого совместимого пакета нужны отдельная папка и уникальный `id`:
строчные латинские буквы, цифры и одиночные дефисы, без дефиса в начале и конце.
В `det_file`, `rec_file` и `dict_file` задаются разные имена файлов этой же папки,
без вложенных путей. Обнаружение пакета ещё не доказывает совместимость ONNX:
она проверяется при загрузке runtime.

## Где TTSBard ищет модели

Пакеты обнаруживаются в двух корнях, строго в этом порядке:

1. Рабочая директория процесса: `<рабочая папка>\models\ocr\`. Её задаёт способ
   запуска — обычно поле «Рабочая папка» в свойствах ярлыка. TTSBard ничего
   не записывает в этот корень.
2. «Данные программы»: `%LOCALAPPDATA%\ttsbard\models\ocr\` либо папка,
   выбранная в настройках TTSBard вместо стандартной.

Пакеты обоих корней видны в списке вместе. При совпадении `id` используется
пакет из рабочей директории. Повреждённый пакет в рабочей директории не
скрывает исправный пакет с тем же `id` в «Данных программы». Кнопка «Открыть
папку» открывает именно «Данные программы». Модели, лежащие рядом с `exe`,
находятся только при запуске с рабочей папкой, равной папке `exe`.

## Включить и проверить

1. Откройте **Интеграция → OCR**.
2. Нажмите **«Обновить список моделей»** и выберите **eSlav PP-OCRv5 Mobile**.
3. Включите **«Включить OCR»**. Дождитесь статуса **«Загружено»**. При ошибке
   прочитайте сообщение в панели; одной включённой галочки недостаточно.
4. В поле **«Экран захвата»** выберите все экраны, основной или конкретный монитор.
   По умолчанию выбраны все экраны. Список обновляется при открытии панели;
   кнопка рядом с полем позволяет обновить его после изменения подключений.
5. Нажмите `Ctrl+Shift+P` и выделите область с несколькими строками текста.
   Выделение открывается на зафиксированном снимке выбранного экрана или всех
   экранов: последующие изменения изображения не меняют выбранный текст.
   `Escape` или щелчок по другому приложению отменяют выделение.
6. Проверьте результат во **«Входящих»**. При включённом автовоспроизведении
   реплика поступает в очередь речи, при выключенном ожидает ручного действия.

Сочетание захвата меняется в **«Горячие клавиши»**. Включённый OCR запускается
также при следующем старте TTSBard. Это однократный захват, постоянного наблюдения
за экраном нет. Настройки разбора реплик описаны в
[руководстве по входящему тексту](./incoming.md#ручной-разбор-входящих).

## Выбор экрана

В режиме расширенного рабочего стола окно со снимком покрывает только выбранный
монитор. На остальных экранах приложения продолжают отображаться. Перемещение
курсора на другой экран само по себе не отменяет выделение; щелчок по другому
приложению отменяет его из-за потери фокуса окна OCR.

«Основной экран» определяется перед каждым захватом. Выбор конкретного монитора
сохраняется между запусками. Если монитор отключён, выбор остаётся недоступным:
захват сообщает об этом и не переключается на другой экран. Подключите монитор
и обновите список либо выберите другой. После смены порта или конфигурации
подключений может потребоваться повторный выбор.

Смена выбора применяется к следующему захвату. В режиме дублирования экранов
оба физических устройства показывают один рабочий стол, включая окно OCR.

## Если модель не работает

| Симптом | Что проверить |
|---|---|
| «Модели не найдены» | Путь в корне моделей (см. «Где TTSBard ищет модели»), один уровень подпапок, точное имя `manifest.json`, совпадение папки с `id`. Затем обновите список. |
| Пакет не появляется | Все четыре файла должны существовать; JSON должен быть корректным, `family` — `pp_ocr_v5`. Несовместимый манифест пропускается. |
| Модель есть в списке, но загрузка завершается ошибкой | Загрузите полный комплект заново; убедитесь, что вместо ONNX не сохранена HTML-страница ошибки и что словарь соответствует распознавателю. |
| После смены файлов используется старая модель | Выключите OCR перед заменой пакета, обновите список и включите снова. |
| Захват не запускается | Дождитесь готовности, проверьте назначенное сочетание. При работе с приложением от администратора см. [FAQ](../faq.md). |
| Текст распознаётся плохо | Выделяйте область плотнее, используйте читаемый размер текста и избегайте переходной анимации; проверьте язык выбранного пакета. |
| Текст появился, но нет звука | Проверьте автовоспроизведение, очередь, готовность TTS-провайдера и аудиовыхода. Это отдельные этапы после OCR. |

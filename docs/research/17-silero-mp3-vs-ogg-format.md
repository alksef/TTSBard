# Silero: есть ли разница между MP3 и OGG

Вопрос: Silero может присылать синтез и как MP3, и как OGG. Отличается ли
качество? Сравнены два реальных ответа бота на одну фразу (~3 с речи, моно
48 kHz), файлы и скрипт: `.work/mp3_ogg/`.

## Что пришли

| | MP3 | OGG |
|---|---|---|
| Кодек | MP3 CBR | Opus VBR (OGG — контейнер) |
| Битрейт | 64 kbps | ~64 kbps |
| Размер | 24.8 КБ / 3.0 с | 24.1 КБ / 3.0 с |

## Измерения (спектральный анализ декодированных PCM)

- 0–14 kHz — идентичны в пределах ±1 dB. Вся разборчивость речи: основа,
  форманты, шипящие до ~10 kHz — в этой полосе, кодеки её не трогают.
- MP3 — жёсткий lowpass на 16 kHz: полоса 16–18 kHz мертва (−73 dB).
- Opus — держит всю полосу до 20 kHz (−37…−42 dB), выше 20 kHz пусто по
  стандарту.
- Средний rolloff (85 % энергии): Opus 8.2 kHz против MP3 7.3 kHz — Opus
  чуть «воздушнее».

## Вывод

Разница есть, но небольшая и только в верхней полосе: при одинаковом битрейте
~64 kbps моно Opus сохраняет диапазон 14–20 kHz («воздух»), MP3 обрезает его
на 16 kHz. На разборчивость и тембр речи это не влияет — оба формата для
TTS-речи звучат практически одинаково, выбор формата критерия качества не
несёт.

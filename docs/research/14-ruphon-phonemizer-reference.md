# Заметка: рассмотреть ruphon для IPA-пути

[Den4ikAI/ruphon](https://github.com/Den4ikAI/ruphon) — IPA-фонемизер от автора
RUAccent на базе ruaccent-encoder (Python, 2025-04). Прямого встраивания в
Rust-приложение нет, но три варианта применения:

1. **Референс алгоритма «ударения → IPA» (главное).** Этап 4 ROADMAP-081
   (Piper) упирается в «как из позиции ударной гласной получить полную фонемную
   строку с корректной редукцией безударных гласных» для raw-phoneme `[[...]]`.
   Код ruphon можно разобрать как спецификацию этого преобразования и
   воспроизвести в Rust-рендерере.
2. **Golden-эталон** при порте и при разработке Piper-рендерера: сравнивать
   IPA-выход нашего кода с его выходом на том же корпусе.
3. **Быстрый product-spike** (Python sidecar на один эксперимент): проверить,
   даёт ли точное IPA реально другое аудио у текущего Piper runtime, до
   вложений в сырой фонемный протокол.

Действие: при старте этапа 4 (Piper adapter) — зачасить ruphon, снять выходы
на омографном regression-наборе ROADMAP-081, решить (1)/(2).

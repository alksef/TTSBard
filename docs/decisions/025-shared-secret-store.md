# DECISION-025 — Общее защищённое хранилище секретов

**Статус:** `accepted`

Принято 2026-10-10 по решению пользователя.

Секреты интеграций хранятся в одном `%APPDATA%\ttsbard\secrets.dat` рядом
с настройками. Модуль `src-tauri/src/secrets.rs` владеет версией общего
документа, разделами по интеграциям, Windows DPAPI текущего пользователя
и атомарной записью. Открытого fallback нет; другие платформы возвращают ошибку.

Типизированные адаптеры интеграций отвечают за собственные схемы и версии.
Первый адаптер — `twitch::credentials`, раздел `twitch`: реквизиты приложения,
авторизации бота и каналов, выбранный канал и служебный токен.
Общее хранилище не знает контрактов Twitch и не доступно через frontend IPC.

Чтение–изменение–запись раздела выполняется под общей процессной блокировкой
`config_write_lock`, включая разные экземпляры хранилища. Запись и удаление
одного раздела сохраняют остальные. Повреждённый файл или неизвестная версия
не заменяются пустым документом. Контракт рассчитан на один процесс приложения;
межпроцессная синхронизация этим модулем не предоставляется.

Миграции из `twitch-api.credentials` нет: формат вводится до выпуска.
Старый файл не читается и автоматически не удаляется; существующую тестовую
авторизацию нужно выполнить заново. Остальные интеграции пока не переведены;
их перенос из открытых настроек требует отдельных задач, включая экспорт
и резервные копии. DPAPI-файл не является переносимым экспортом секретов.

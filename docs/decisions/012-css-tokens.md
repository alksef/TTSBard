# DECISION-012 — CSS tokens и темы

**Статус:** `accepted`

## Контекст

Несколько панелей и окон должны сохранять единый вид в тёмной и светлой теме.

## Решение

Цвета, поверхности, состояния и размеры задаются семантическими CSS variables.
Светлая тема переопределяет tokens через theme attribute.

Для унификации основных форм согласован общий CSS-слой (2026-10-03):
`src/styles/ui-tokens.css` хранит значения типографики, геометрии и отступов,
`src/styles/ui-controls.css` — явно подключаемые классы `ui-*`.
Размеры текста задаются в `rem`, геометрия — в `px`; цвета берутся из
существующих токенов темы. Значения и исключения описаны в
[UI guidelines](../development/ui-guidelines.md).

Панели переходят на эти классы постепенно, по отдельным задачам. Общий слой
не переопределяет все `input`, `button`, `label` или старые классы панелей.
Так можно проверять каждую миграцию отдельно и сохранять плотность
специализированных контролов. Общий framework Vue-компонентов этим решением
не вводится; его необходимость рассматривается отдельно.

## Последствия

Компоненты не вводят локальную палитру без необходимости. Новое состояние
проверяется в обеих темах; существующий компонент служит визуальным эталоном.

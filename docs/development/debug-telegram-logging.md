# Текст ответов Silero в debug-логах

Для диагностики изменившегося формата ответов Telegram-бота можно явно включить
логирование полного текста входящих сообщений от `@silero_voice_bot`:

```powershell
$env:TTSBARD_LOG_TELEGRAM_TEXT = "1"
./scripts/build.ps1 -Mode debug
./src-tauri/target/debug/ttsbard.exe
```

Переменную нужно задать в том же PowerShell, из которого запускается приложение.
В консоли и файле лога записи имеют target `silero_inbound_text`; запись в файл
дополнительно требует включённого логирования в настройках приложения. Возможны
повторные записи одного Telegram update, если его одновременно читают несколько
подписчиков.

Режим включается только при точном значении `1` и только в debug-сборке. В
release-сборке код вывода текста заменён на compile-time no-op, поэтому переменная
окружения не действует. Исходящие TTS-фразы, сообщения других Telegram peers и
данные авторизации эта диагностика не записывает.

Текст ответа Silero может содержать сведения об аккаунте и лимитах. Перед
передачей debug-лога третьим лицам его нужно проверить и при необходимости
очистить. После диагностики переменную можно удалить из текущей сессии:

```powershell
Remove-Item Env:TTSBARD_LOG_TELEGRAM_TEXT
```

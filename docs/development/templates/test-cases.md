# Шаблон ручных тест-кейсов

Скелет документа ручных тест-кейсов. Копируется в
`.work/testcase/YYYY-MM-DD-manual-testcases.md` (при коллизии имени — с
суффиксом `-2`, `-3` перед расширением) и заполняется по
[нормативу](../test-cases.md). Сам заполненный отчёт не коммитится — он
рабочий артефакт сессии.

Приоритеты: 🔴 P0 (user-visible, обязательно) · 🟡 P1 (нишевое/скрытое) ·
⚪ P2 (архитектура, косвенно через логи/автотесты).

````markdown
# Ручные тест-кейсы: диапазон <от тега>..<HEAD или тема>

Создан: YYYY-MM-DD.
Контекст: <одна-две строки — что проверяется и почему именно сейчас>.
Все автопроверки (npm test, cargo test, clippy, contract-gates) уже зелёные;
здесь — только то, что требует запущенного приложения и реальных интеграций.

Предусловия для запуска приложения: <команда запуска, напр. pnpm tauri dev>.

---

## A. <Группа> — ROADMAP-NNN «<тема>»  🔴 P0

Затронутые коммиты: `<sha> ...` (с пометками P0/P1/P2).
Панель/бэкенд: `<файлы>`.

### A1. <Краткое название кейса> (P0)  🔴
1. <шаг воспроизведения>
2. <шаг>
   - ✅ <ожидаемый результат>
   - ❌ Регрессия: <что считать багом>

### A2. <Краткое название> (P1)  🟡
1. <шаги>
   - ✅ <ожидание>

---

## Чеклист прохождения

````
[ ] A1  <название>            (P0)
[ ] A2  <название>            (P1)
````

Правила заполнения:

- Один roadmap-трек = одна группа (A, B, C…), даже если разложен на приоритеты.
- Каждый кейс: нумерованные шаги → ✅ ожидание → ❌ маркер регрессии (где уместно).
- Имена полей/кнопок/команд — из кода (`git show`, roadmap-документы), не по памяти.
- P2-кейсы (архитектура) сводятся к ссылке на автотест/команду, если нет
  наблюдаемого эффекта.
- Закрыть чеклист можно только фактически выполнив кейс; формальная простановка
  галочек без проверки недопустима (см. memory: review-чекбоксы ненадёжны).
````

## Пример заполнения одного кейса

````markdown
### A3. Socket остаётся жив при семантических ошибках VTS (P1)  🔴
1. Подключиться к VTS. Ввести конфликтное имя параметра.
2. Нажать «Тест действия».
   - ✅ Понятная ошибка, статус «Подключено», без реконнекта.
   - ❌ Регрессия: семантическая ошибка рвёт сокет — баг P1.
````

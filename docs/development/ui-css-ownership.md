# Владельцы CSS и реестр исключений UI

Этот файл — общий навигатор для аудита локального оформления, не подтверждение
визуальной приёмки. Согласованные значения задают [UI guidelines](./ui-guidelines.md),
источники экранов — [карта UI](./ui-map.md). Новые варианты ниже со статусом
«предложение» не являются общим стандартом.

## Разделение ответственности

| Слой | Владелец | Что задаёт |
|---|---|---|
| Темы | `src/styles/variables.css` | Семантические цвета, обе темы, цветовая схема нативных списков |
| Размеры и роли | `src/styles/ui-tokens.css` | rem-типографика, веса, геометрия обычных контролов и отступы |
| Обычные контролы | `src/styles/ui-controls.css` | Явные классы ui-*, состояние focus/disabled, меню и вкладки |
| Поверхность окна | `src/App.vue`, `src/style.css`, профильные entrypoints | Фон, прозрачность, корневая типографика, границы окон |
| Раскладка экрана | CSS владельца Vue-компонента | Колонки, ширины по назначению, responsive-переносы, расположение подсказок |
| Специализированные области | Владельцы в реестре ниже | Только обозначенные отличия; не собственная копия всех обычных контролов |

Локальные display/grid/flex, width/max-width, позиционирование и media/container
queries сами по себе не являются излишней кастомизацией. Их вынос не требуется
только ради уменьшения числа строк CSS. Цвет смыслового состояния (ошибка,
подключение) также не является дефектом, если использует семантический token.

## Правило дальнейших правок

Перед добавлением override общего класса найти его роль и запись реестра.
Сохраняемая локальная раскладка получает объяснение в компоненте, если оно
неочевидно. Отступление от стандартной геометрии/типографики требует конкретной
причины и статуса: согласовано, совместимость, текущее сохранённое или предложение.
Совпадение с существующим UI само по себе не означает согласования.

Повторяющийся вариант сначала описывается здесь и согласуется; затем добавляется
явный ui-модификатор и мигрируются владельцы. Не вводить !important, глобальное
переопределение всех button/input или широкое совпадение старых классов панелей.
CSS runtime исключений пока остаётся у владельцев; этот файл централизует
объяснения и навигацию без изменения архитектуры загрузки стилей.

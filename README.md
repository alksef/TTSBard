# TTSBard

**Быстрый голос для общения и стриминга — без лишних переключений между окнами.**

TTSBard создан для людей, использующих синтез речи в повседневном общении или стриминге. Быстрый редактор с несколькими вкладками и историей сообщений вызывается по глобальной горячей клавише: главное окно появляется поверх остальных и получает фокус. После отправки фразы оно может остаться активным, скрыться или вернуть фокус предыдущему окну. Несколько TTS-провайдеров, аудиокэш, саундпад и интеграции с OBS и Twitch собраны в одном месте.

## Для кого

Приложение создавалось для двух аудиторий с общим знаменателем — «быстро превратить мысль в голос»:

- **Люди с ограничениями речи**, использующие синтез речи как основной способ общения.
- **Стримеры и контент-мейкеры**, использующие озвучку и звуковую панель на трансляциях (Twitch, YouTube). Для них важны озвучка в реальном времени, наборы звуков, OBS-интеграция и скорость реакции прямо во время игры.

## История проекта

Всё началось с [интервью на YouTube](https://www.youtube.com/watch?v=O6StzI8CCx0) с участием стримеров [megubite](https://www.twitch.tv/megubite) и [alexxa69419](https://www.twitch.tv/alexxa69419).

Наблюдая за трансляциями [alexxa69419](https://www.twitch.tv/alexxa69419), глубже погрузился в тему TTS и через неё узнал о существовании целого комьюнити стримеров, общающихся с аудиторией исключительно с помощью синтеза речи: [pirunka_tsd](https://www.twitch.tv/pirunka_tsd), [weissstille](https://www.twitch.tv/weissstille), [safutara_kaino](https://www.twitch.tv/safutara_kaino).

Стримеры используют программу **TTS Voice Wizard** в связке с Python-скриптом [TTS-Wizard-2-Silero-Telegram-Bot](https://github.com/alexxa69420/TTS-Wizard-2-Silero-Telegram-Bot) (написанным `alexxa69419`) для интеграции с Telegram-ботом [@silero_voice_bot](https://t.me/silero_voice_bot). Также `alexxa69419` разработала вспомогательную утилиту [randompad](https://github.com/alexxa69420/randompad) — написанный с помощью нейросетей саундпад, который при нажатии одной горячей клавиши воспроизводит случайный звук из заранее заданного набора. А у [pirunka_tsd](https://www.twitch.tv/pirunka_tsd) была подсмотрена идея вывода произносимого текста прямо в OBS Studio для удобства зрителей.

Хотя TTS Voice Wizard — мощный инструмент, он перегружен лишними функциями (так как изначально создавался под VRChat) и не имеет встроенного вывода текста в OBS. Но самым главный недостаток - необходимость переключаться на окно программы через `Alt+Tab` для ввода каждой новой фразы.

В эпоху современных ИИ-агентов («вайб-кодинга») появилась возможность создать единое фоновое приложение для быстрого TTS-общения без постоянного переключения между окнами. В нём объединились быстрый редактор, несколько TTS-провайдеров, аудиокэш, саундпад, вывод текста в OBS и отправка реплик в Twitch Chat. Так и родился **TTSBard**.

## Какие проблемы решает TTSBard

В основу проекта легли три основные проблемы существующих TTS-приложений:

- медленный набор и отправка реплик;
- постоянное переключение между окнами;
- отсутствие единого пространства для TTS, саундпада и стриминговых интеграций.

TTSBard создаётся как фоновое приложение, сокращающее путь от мысли до озвученной фразы. Подробнее об исходной постановке задачи — в [PROBLEMS.md](PROBLEMS.md).

## Решение

**TTSBard** — это незаметное TTS-приложение, которое работает в фоновом режиме и доступно мгновенно по горячей клавише в любом приложении.

### Как ведёт себя главное окно

По глобальной горячей клавише TTSBard показывает главное окно поверх остальных и переводит фокус в редактор, чтобы можно было сразу начать печатать.

Дальнейшее поведение настраивается в режиме быстрого редактора:

- **Отключено** — после отправки окно остаётся активным;
- **Сворачивать** — после отправки или нажатия `Escape` главное окно скрывается, а приложение продолжает работать в трее;
- **Возвращать фокус** — главное окно остаётся видимым, но управление возвращается окну, которое было активно до вызова TTSBard.

Возврат фокуса работает, если главное окно было вызвано глобальной горячей клавишей.

### Основной сценарий использования

1. Нажали `Ctrl+Shift+F3` — главное окно с редактором мгновенно появляется поверх всех окон и получает фокус.
2. Ввели текст (можно использовать вкладки для параллельной работы или автодополнение по истории).
3. Нажали `Enter` (или кликнули кнопку отправки) — текст отправляется в TTS и озвучивается.
4. После отправки окно остаётся активным, скрывается или возвращает фокус предыдущему приложению — в зависимости от настройки быстрого редактора. `Escape` выполняет выбранное действие без отправки текста.

### TTS провайдеры

**Silero Bot**
- Озвучка через Telegram-бота [@silero_voice_bot](https://t.me/silero_voice_bot) с использованием личного Telegram-аккаунта.
- Авторизация по номеру телефона с поддержкой облачного пароля Telegram (2FA).
- Выбор и сохранение голосов, просмотр лимитов аккаунта.
- Поддержка встроенного MTProxy и Socks5.

**Piper**
- Локальный синтез речи с помощью Piper-совместимых голосовых моделей.
- Каждая установленная модель доступна как отдельный TTS-провайдер.
- Модели автоматически обнаруживаются в `%APPDATA%\TTSBard\models\piper`.
- Работает без подключения к интернету и отдельного HTTP-сервера.
- Модель загружается только при её выборе.

**OpenAI TTS**
- 6 естественных голосов: alloy, echo, fable, onyx, nova, shimmer
- Настройка скорости (0.25-4.0)
- Поддержка прокси
- Требуется API ключ

**Local HTTP TTS**
- Режим "Locally Hosted" из TTS Voice Wizard
- HTTP запросы к локальному серверу (TITTS.py или совместимый)
- Работает без интернета
- URL по умолчанию: `http://127.0.0.1:8124`

**Fish Audio TTS**
- Синтез речи на основе кастомных и загруженных голосовых моделей
- Настройка референсных аудиофайлов для клонирования голоса
- Выбор моделей через UI
- Требуется API ключ

### Аудио вывод

**Dual output** — одновременное воспроизведение на два устройства:
- **Динамики** — выбор устройства, громкость, вкл/выкл
- **Виртуальный микрофон** — VB-Cable, VoiceMeeter и др.

### Главное окно и системный трей

**Идея:** Приложение всегда доступно, но не мешает работе.

**Как это работает:**
- При закрытии главного окна оно **не закрывается**, а сворачивается в **системный трей** (область уведомлений Windows)
- Двойной клик по иконке разворачивает окно
- Правый клик открывает контекстное меню (Выход)

**Преимущества:**
- ✅ Приложение всегда под рукой
- ✅ Не загромождает панель задач
- ✅ Быстрый доступ без Alt+Tab
- ✅ **Защита от захвата экрана:** возможность сделать окна приложения (настройки, саундпад, плеер) невидимыми для OBS, Discord и других программ записи, предотвращая утечку API-ключей и токенов в эфир.

### Продвинутый редактор текста

Встроенный текстовый редактор на базе **CodeMirror 6** специально разработан для быстрого и комфортного набора текста без отвлечения от основного занятия.

**Возможности:**
- **Независимые вкладки (Tabs):** Поддержка создания нескольких параллельных вкладок с возможностью быстрого переключения между ними (по аналогии с вкладками в браузере или IDE). Содержимое вкладок, их порядок и активное состояние автоматически сохраняются между перезапусками приложения.
- **Офлайн-проверка орфографии:** Локальная проверка орфографии в реальном времени (на базе Hunspell) без обращения к внешним онлайн-сервисам.
- **История слов и автодополнение:** Приложение собирает историю введенных слов в персональный словарь (сохраняется в `input_history.json` между сессиями) и предлагает умные подсказки по подстроке во время набора, ускоряя общение.
- **Журнал истории фраз:** Быстрый поиск и вставка ранее отправленных реплик (хранятся в `phrase_history.json`) в двух режимах: **добавление** в конец текущей строки или полная **замена** текста в редакторе (с подтверждением для защиты от перезаписи).
- **Кэш аудио:** Готовая озвучка сохраняется локально и доступна для повторного воспроизведения из истории фраз без нового обращения к TTS-провайдеру.
- **Макросы и быстрая вставка:** Поддержка пресетов быстрой замены фраз (`\name` и `%username`), которые автоматически преобразуются в текст при нажатии пробела в процессе набора.
- **Числовой препроцессор:** Автоматическая конвертация чисел в слова с правильным грамматическим согласованием рода и множественного числа прямо в редакторе.
- **Маршрутизация вывода:** Префиксы в начале текста (`!` — отправить в OBS/WebView, `!!` — отправить только в TTS, без префикса — отправить везде) позволяют гибко управлять выходом фразы в Twitch и WebView.
- **Удобная отправка:** Клавиша `Enter` мгновенно отправляет текст на озвучку. После отправки окно остаётся активным, скрывается или возвращает фокус предыдущему окну — в зависимости от настройки быстрого редактора. `Escape` выполняет выбранное действие без отправки текста.

### AI-коррекция текста (экспериментальная функция)

Экспериментальное интеллектуальное исправление ваших фраз «на лету» перед озвучиванием.

**Возможности:**
- Поддержка провайдеров **OpenAI** (GPT-4o/GPT-3.5), **DeepSeek** (direct API) и **Z.ai**.
- **Кастомный системный промпт:** Настройка инструкций для ИИ (например, для исправления опечаток, пунктуации или изменения стиля фразы).
- **Тумблер в редакторе:** Быстрое включение/выключение AI-коррекции прямо в окне набора текста.

### Звуковая панель (Саунпад)

**Идея:** отдельное плавающее окно с сеткой клавиатуры для воспроизведения и
настройки звуков без перехода в боковое меню.

**Как это работает:**
1. Нажмите `Ctrl+Shift+F2` — панель появится поверх игры и получит фокус.
2. Переключитесь в config через `Ctrl+B` и назначьте файлы ячейкам `A–Z`/`0–9`.
3. Вернитесь в runtime и нажмите клавишу, `Enter` или ячейку мышью.

**Возможности:**
- **Слои:** независимые профили переключаются селектом, `PageUp`/`PageDown`
  или напрямую `F1–F12` по порядковому номеру.
- **Клавиатурная сетка:** до 36 привязок на слой — `A–Z` и `0–9`.
- **Runtime/config:** `Ctrl+B` переключает запуск звуков и назначение файлов.
- **Поддерживаемые форматы:** MP3, WAV, OGG, FLAC, M4A, AAC и WMA.
- **Закрепление:** кнопка-гвоздик сохраняет панель видимой после клика, Enter,
  физической клавиши, Escape и потери фокуса.
- **Аудиоканалы:** каждый звук использует те же выбранные динамики и
  виртуальный микрофон, что и TTS, с их отдельными уровнями громкости.
- **Очередь звуков:** быстрые нажатия выполняются по порядку и не накладывают
  звуки друг на друга. Очередь панели независима от очереди речи: SoundPanel
  не прерывает TTS и не ждёт окончания произносимой фразы.
- **Возврат фокуса:** Перед воспроизведением или после `Escape` фокус возвращается в окно, активное до вызова панели. Если закрепление выключено, панель дополнительно скрывается.
- **Управление окном:** Закреплённую панель можно перетаскивать за заголовок; кнопка `×` всегда закрывает её.
- **Оформление:** цвет наследуется от главного окна или задаётся отдельно;
  прозрачность SoundPanel всегда имеет собственную шкалу `0–90%` в настройках интерфейса.

**Глобальные горячие клавиши:**
- `Ctrl+Shift+F2` — показать и сфокусировать панель

Остальные клавиши работают локально только в активной панели. Подробности — в
[руководстве по SoundPanel](docs/user/soundpanel.md).

### Оверлей для OBS (WebView-сервер)

**Идея:** Отображение текста в реальном времени в OBS Studio или браузере через Server-Sent Events (SSE).

**Как это работает:**
1. Включите оверлей для OBS (WebView-сервер) в настройках (по умолчанию порт 10100)
2. Добавьте Browser Source в OBS: `http://localhost:10100`
3. Отправьте текст в TTS — текст появится в OBS мгновенно

**Возможности:**
- SSE (Server-Sent Events) для real-time обновлений
- Настраиваемый порт и bind address (0.0.0.0 / 127.0.0.1)
- Полная кастомизация HTML/CSS шаблонов (папка в config)
- Токен-аутентификация для внешних подключений
- UPnP — автоматический проброс портов на роутере
- Автозапуск при старте приложения

**Настройка в OBS:**
1. Источники → Добавить → Browser Source
2. URL: `http://localhost:10100`

**Внешнее подключение (для коллабораций):** вы можете открыть доступ к своему оверлею (WebView-серверу) из интернета (включив UPnP в настройках или настроив port forwarding на роутере вручную). Это позволяет передавать поток озвучиваемых сообщений на удаленные системы. Например, во время совместных стримов другой стример может добавить вашу ссылку (защищенную токеном авторизации) в качестве Browser Source в свой OBS, чтобы субтитры ваших реплик выводились прямо у него на трансляции в реальном времени.

### Twitch Chat

**Идея:** Отправка TTS сообщений в Twitch чат для дублирования ТТС.

**Как это работает:**
1. Создайте Twitch бота на [twitchtokengenerator.com](https://twitchtokengenerator.com)
2. Скопируйте OAuth токен со страницы (только сам токен, без префикса)
3. Введите данные в настройках Twitch Chat
4. Нажмите Start для подключения к чату

**Возможности:**
- Автоматическое переподключение при изменении настроек
- Start on boot — автоподключение при запуске приложения
- Тестовое сообщение для проверки подключения

### VTube Studio

TTSBard передаёт в VTube Studio состояние набора текста, не отправляя модели сам текст или звук. Поддерживаются три действия:

- **Параметр VTS:** TTSBard создаёт собственный INPUT и передаёт значения `1` во время набора и `0` после его окончания. INPUT нужно сопоставить с нужным Live2D OUTPUT в VTS Parameter Setup.
- **Горячие клавиши:** При начале и окончании набора запускаются две выбранные Hotkey текущей модели.
- **Предмет сцены:** Выбранный PNG, JPG, GIF или animation-folder показывается во время набора и скрывается после него.

Настройка действия доступна только при живом подключении. Сохранённые значения не теряются при отключении, а ошибки отдельной команды не разрывают исправную сессию. Подключение, безопасное переименование INPUT и диагностика описаны в [руководстве по VTube Studio](docs/integrations/vtube-studio.md).

### Панель управления воспроизведением

Плавающее окно управления воспроизведением (Playback Control) предоставляет контроль над озвучиваемым текстом в реальном времени.

**Возможности:**
- **Управление воспроизведением:** Кнопки паузы, полной остановки (Stop) и воспроизведения фразы сначала.
- **История озвучки:** Быстрый повтор ранее озвученных фраз непосредственно из кэша воспроизведения.

### Экспериментальный перехват клавиш (Numpad Control)

Numpad Control использует глобальный перехват клавиш и работает независимо от активного приложения. На цифры и служебные клавиши цифрового блока, а также `F1–F24` можно назначить показ главного окна, саундпада или Playback Control, паузу и продолжение воспроизведения, остановку и повтор фразы. Назначенная клавиша поглощается вместо обычного ввода; остальные клавиши передаются активному приложению без изменений. Техническая реализация глобального перехвата через `WH_KEYBOARD_LL` описана ниже.

## Технологии

- **Tauri 2.0** — десктопный фреймворк
- **Vue.js 3** — UI (Composition API, composables для состояния)
- **CodeMirror 6** — текстовый редактор с автодополнением и спеллчекером
- **Rust** — backend (многопоточность, системные хуки)
- **Tokio** — async runtime
- **Windows API** — WH_KEYBOARD_LL для перехвата клавиатурного ввода
- **Axum** — встроенный веб-сервер для OBS (WebView)
- **Rodio** — библиотека воспроизведения аудио

### Как работает глобальный перехват (WH_KEYBOARD_LL)

TTSBard использует **Windows Low-Level Keyboard Hook** (`WH_KEYBOARD_LL`) для обработки глобальных горячих клавиш и экспериментального режима Numpad Control. Этот механизм Windows API позволяет приложению регистрировать нажатия клавиш без постоянного удержания фокуса на главном окне.

**Технические детали:**

| Аспект | Описание |
|--------|----------|
| **Тип хука** | `WH_KEYBOARD_LL` (Low-Level) |
| **Уровень** | User-mode (не требует драйвера ядра) |
| **Область действия** | Глобальная (все приложения системы) |
| **Функция API** | `SetWindowsHookExW` |

**Как это работает:**

1. **Регистрация хука** — приложение вызывает `SetWindowsHookExW` с типом `WH_KEYBOARD_LL`.
2. **Фильтрация событий** — в отличие от полной блокировки ввода, хук перехватывает и поглощает только назначенные функциональные клавиши (например, блок Numpad в режиме перехвата) для вызова действий приложения.
3. **Пропуск трафика** — все остальные клавиши передаются операционной системе без задержек и изменений через `CallNextHookEx`.
4. **Удаление хука** — при закрытии приложения хук автоматически удаляется.

**Преимущества подхода:**
- ✅ Не требует драйвера ядра (работает в user-mode).
- ✅ Точечно фильтрует только зарегистрированные клавиши управления, не влияя на обычный набор текста.
- ✅ Минимальное влияние на производительность системы.

**Ограничения:**
- ❌ Не перехватывает клавиши, когда фокус находится в приложениях с правами Администратора.
- ❌ Не может блокировать системные комбинации (например, `Ctrl+Alt+Del`).
- ❌ Доступно только для Windows 10/11.
